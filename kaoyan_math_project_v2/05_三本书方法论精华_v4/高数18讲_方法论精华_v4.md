## 全局OPD框架

### H00-001｜OPD总入口
- 来源页：前言
- 看到：拿到任意数学题，题干很长或选项很多
- 应想到：先只问一个问题：题目最终要我得到什么？这是O。
- 第一动作：把题干、选项、设问一起看，写下“计算/证明/判断/求参/分类”的目标
- 动作链：把题干、选项、设问一起看，写下“计算/证明/判断/求参/分类”的目标；多问题分成O1,O2,…。
- 断点提醒：若还没写出目标就开始算，容易被细节带偏。
- 错因倾向：目标识别断点 / 方法论调取失败

### H00-002｜OPD总入口
- 来源页：前言
- 看到：已知条件很多，但不知道从哪下手
- 应想到：进入P：从已知推、从结论倒推，或两头同时推。
- 第一动作：正向走已知能直接给出的公式
- 动作链：正向走已知能直接给出的公式；反向把欲证结论改写成充分条件；若中间能接上，就是双向思路。
- 断点提醒：证明题尤其要把“想证A”改写成“只需证B”。
- 错因倾向：条件检查遗漏 / 动作链断裂

### H00-003｜OPD总入口
- 来源页：前言
- 看到：结论显然像是真的，但正推不动
- 应想到：考虑反证或逆否。
- 第一动作：假设结论不成立，推出与已知、定义、符号、正负性、秩/维数等矛盾
- 动作链：假设结论不成立，推出与已知、定义、符号、正负性、秩/维数等矛盾；或者改证逆否命题。
- 断点提醒：“不存在”“至多”“唯一”类题常适合反证。
- 错因倾向：方法论调取失败 / 动作链断裂

### H00-004｜OPD总入口
- 来源页：前言
- 看到：题中含自然数n、n阶对象、递推、行列式阶数
- 应想到：考虑数学归纳或递推。
- 第一动作：先算小n观察结构
- 动作链：先算小n观察结构；写n=k假设；证明n=k+1；若关系涉及更早项，用第二归纳法。
- 断点提醒：归纳不是最后补格式，而是用假设创造条件。
- 错因倾向：方法论调取失败 / 动作链断裂

### H00-005｜细节D体系
- 来源页：前言
- 看到：一个符号、函数、矩阵、区域看似普通
- 应想到：先观察研究对象，挖隐含条件。
- 第一动作：查定义域、零点、分段点、奇偶性、周期性、对称性、秩、可逆性、正定性、矩阵形状、区域边界
- 动作链：查定义域、零点、分段点、奇偶性、周期性、对称性、秩、可逆性、正定性、矩阵形状、区域边界。
- 断点提醒：很多题的“钥匙”藏在对象本身，而不是题干明说。
- 错因倾向：条件检查遗漏 / 动作链断裂

### H00-006｜细节D体系
- 来源页：前言
- 看到：题干用文字、几何、物理、经济语言描述
- 应想到：转换等价表述。
- 第一动作：把“变化率、距离、公共解、同解、相似、合同、正定、连续、可导”等翻译成方程、极限、秩、矩阵或积分
- 动作链：把“变化率、距离、公共解、同解、相似、合同、正定、连续、可导”等翻译成方程、极限、秩、矩阵或积分。
- 断点提醒：如果卡在读题，先写等价数学表达，不要急算。
- 错因倾向：方法论调取失败 / 动作链断裂

### H00-007｜细节D体系

- 动作链：通过恒等变形、提因子、通分、有理化、换元、分块、相似对角化、泰勒、微分方程等，把它变成已知模板。
- 断点提醒：问自己：它能不能变成我见过的基本型？
- 错因倾向：方法论调取失败 / 动作链断裂

### H00-008｜细节D体系

- 应想到：移花接木：按题目指令把D与D接起来。
- 第一动作：例如“级数+微分方程”“矩阵方程+特征值”“二次型+正定”“积分+泰勒”，先各自标准化，再连接
- 动作链：例如“级数+微分方程”“矩阵方程+特征值”“二次型+正定”“积分+泰勒”，先各自标准化，再连接。
- 断点提醒：综合题不是凭灵感，是把局部模块串联。
- 错因倾向：方法论调取失败 / 动作链断裂

### H00-009｜细节D体系
- 来源页：前言
- 看到：抽象结论难以判断
- 应想到：试特殊情形。
- 第一动作：取0、1、单位矩阵、对角矩阵、低阶n、对称区域、简单函数，检验真假、猜结构、找反例
- 动作链：取0、1、单位矩阵、对角矩阵、低阶n、对称区域、简单函数，检验真假、猜结构、找反例。
- 断点提醒：选择题、必要/充分判断特别要做。
- 错因倾向：目标识别断点 / 方法论调取失败

### H00-010｜细节D体系

- 应想到：引入符号。
- 第一动作：给距离、面积、体积、部分和、矩阵列、参数曲线、区域边界命名，再建立方程

## 第1讲 函数极限与连续

### H01-001｜极限计算总流程
- 来源页：p1-12
- 看到：看到极限计算
- 应想到：第一步不是算，而是判定类型。
- 第一动作：代入趋势，识别是否为0/0、∞/∞、0·∞、∞-∞、1^∞、0^0、∞^0
- 动作链：代入趋势，识别是否为0/0、∞/∞、0·∞、∞-∞、1^∞、0^0、∞^0；确定后再选洛必达、等价、泰勒、对数化等。
- 断点提醒：若不是未定式，通常直接用连续性或极限四则。
- 错因倾向：目标识别断点 / 方法论调取失败

### H01-002｜幂指型极限
- 来源页：p1-12
- 看到：看到u(x)^{v(x)}，尤其u→1
- 应想到：立刻想到对数化，把指数型转成乘积型。
- 第一动作：令L=lim v ln u
- 动作链：令L=lim v ln u；若u=1+α且α→0，则ln u~α，重点计算vα。
- 断点提醒：不要直接把1^∞当成1。
- 错因倾向：目标识别断点 / 方法论调取失败

### H01-003｜整体与局部未定式
- 来源页：p1-12
- 看到：外层不明显但局部含未定式
- 应想到：把局部表达式单独判定。
- 第一动作：例如指数、对数、三角、变上限积分内部先做等价，再回到整体
- 动作链：例如指数、对数、三角、变上限积分内部先做等价，再回到整体。
- 断点提醒：变量名可能从n写成t、从x写成1/n，形式变了本质不变。
- 错因倾向：方法论调取失败 / 动作链断裂

### H01-004｜无穷小比较
- 来源页：p1-12
- 看到：看到sin、tan、arcsin、ln(1+x)、e^x-1、1-cosx等趋0
- 应想到：先调用常用等价无穷小。
- 第一动作：普通型直接替换
- 动作链：普通型直接替换；差函数型用更高阶展开；复合型先判断内层等价；变上限积分用“积分长度×端点主值/积分主阶”。
- 断点提醒：差函数不能只用一阶等价，否则会被抵消。
- 错因倾向：目标识别断点 / 方法论调取失败

### H01-005｜差函数极限
- 来源页：p1-12
- 看到：看到同类函数差：f(a_n)-f(b_n)、三角差、对数差、反三角差
- 应想到：想到拉格朗日中值定理或泰勒。
- 第一动作：把差写成f′(ξ)(a_n-b_n)，再估阶
- 动作链：把差写成f′(ξ)(a_n-b_n)，再估阶；若在特殊点，展开到首个非零项。
- 断点提醒：尤其适合∞-∞的局部差。
- 错因倾向：目标识别断点 / 方法论调取失败

### H01-006｜∞-∞处理
- 来源页：p1-12
- 看到：看到∞-∞或大项相减
- 应想到：总方向：把和差化成乘除或提主项。
- 第一动作：有根式就有理化
- 动作链：有根式就有理化；有分式就通分；有指数幂就提主因子；有函数差用中值定理。
- 断点提醒：不要让两个∞直接相减。
- 错因倾向：目标识别断点 / 方法论调取失败

### H01-007｜带有振荡/有界因子
- 来源页：p1-12
- 看到：看到(-1)^n、sin n、cos n、sin(1/x)等有界但不收敛因子
- 应想到：想到“无穷小×有界量=无穷小”。
- 第一动作：寻找或制造趋0因子，把振荡影响压掉
- 动作链：寻找或制造趋0因子，把振荡影响压掉；若无趋0因子，要考虑不存在。
- 断点提醒：有界不唯一不能直接取极限。
- 错因倾向：目标识别断点 / 方法论调取失败

### H01-008｜连续与间断
- 来源页：p1-12
- 看到：判断连续/间断点
- 应想到：先找候选点：无定义点、分母零点、分段点、取整点、绝对值转折点。
- 第一动作：分别算左极限、右极限和函数值
- 动作链：分别算左极限、右极限和函数值；按跳跃、可去、无穷、振荡分类。
- 断点提醒：不要在普通点浪费时间，先盯异常点。
- 错因倾向：目标识别断点 / 方法论调取失败

### H01-009｜极限微观性态
- 来源页：p1-12
- 看到：题目问局部正负、大小、存在性、函数趋近状态
- 应想到：用定义、局部保号、夹逼、单调有界。
- 第一动作：把lim f=A翻译成|f-A|<ε
- 动作链：把lim f=A翻译成|f-A|<ε；A>0推出邻域内f>0；夹逼要构造上下同极限；单调有界用于存在性。
- 断点提醒：“脱帽严格、戴帽非严格”：极限正可推局部正；局部非负只能推极限非负。
- 错因倾向：条件检查遗漏 / 动作链断裂

### H01-010｜含参极限
- 来源页：p1-12
- 看到：极限存在或有限，求参数
- 应想到：把“极限存在/有限”转成主项消失或左右一致。
- 第一动作：展开到可能发散或不一致的最低阶，令其系数为0
- 动作链：展开到可能发散或不一致的最低阶，令其系数为0；再验证剩余项。
- 断点提醒：求参题要防止只解必要条件不验证。
- 错因倾向：目标识别断点 / 方法论调取失败

## 第2讲 数列极限

### H02-001｜数列极限总流程
- 来源页：p13-21
- 看到：看到递推数列或判断lim x_n
- 应想到：先判断形式：等式递推、不等式递推、复合迭代、双通项、初值影响。
- 第一动作：若能证明收敛，极限通常代入固定点方程
- 动作链：若能证明收敛，极限通常代入固定点方程；若不能，先证明有界单调/压缩/夹逼。
- 断点提醒：不能直接把n→∞代入递推，先证明极限存在。
- 错因倾向：目标识别断点 / 方法论调取失败

### H02-002｜压缩映射
- 来源页：p13-21
- 看到：看到x_{n+1}=f(x_n)，且f可导、|f′|可能<1
- 应想到：想到压缩映射。
- 第一动作：找固定点a=f(a)，用中值定理估|x_{n+1}-a|≤k|x_n-a|，再夹逼收敛到a
- 动作链：找固定点a=f(a)，用中值定理估|x_{n+1}-a|≤k|x_n-a|，再夹逼收敛到a。
- 断点提醒：要说明a唯一或序列进入有效区间。
- 错因倾向：目标识别断点 / 方法论调取失败

### H02-003｜单调有界
- 来源页：p13-21
- 看到：递推式能比较x_{n+1}与x_n，或能找到上下界
- 应想到：想到单调有界准则。
- 第一动作：先用归纳证明序列落在区间，再证明单调
- 动作链：先用归纳证明序列落在区间，再证明单调；极限L满足L=f(L)或由夹逼得到。
- 断点提醒：单调性常要借助函数f(x)-x的符号。
- 错因倾向：条件检查遗漏 / 动作链断裂

### H02-004｜递推等式关系
- 来源页：p13-21
- 看到：看到f(x_n,x_{n+1})=0
- 应想到：化归为差分、比值、固定点或不变量。
- 第一动作：把x_{n+1}单独解出，或构造x_{n+1}-a与x_n-a关系
- 动作链：把x_{n+1}单独解出，或构造x_{n+1}-a与x_n-a关系；必要时用有理化、配方、取倒数。
- 断点提醒：目标是得到可迭代的等式/不等式。
- 错因倾向：目标识别断点 / 方法论调取失败

### H02-005｜递推不等式关系
- 来源页：p13-21
- 看到：看到x_{n+1}≤g(x_n)或含x_n,x_{n+1}不等式
- 应想到：想到夹逼、单调界、递推估计。
- 第一动作：把x_{n+1}-a与x_n-a比较，或构造辅助数列控制误差
- 动作链：把x_{n+1}-a与x_n-a比较，或构造辅助数列控制误差。
- 断点提醒：先确认不等式方向不会随变形改变。
- 错因倾向：目标识别断点 / 方法论调取失败

### H02-006｜初值影响
- 来源页：p13-21
- 看到：题目强调x_1或初值范围
- 应想到：想到不同初值可能进入不同不变区间或趋向不同固定点。
- 第一动作：画/分析y=f(x)与y=x交点，判断迭代方向
- 动作链：画/分析y=f(x)与y=x交点，判断迭代方向；分区间证明。
- 断点提醒：不要只代一个初值猜结论。
- 错因倾向：方法论调取失败 / 动作链断裂

### H02-007｜复合迭代
- 来源页：p13-21
- 看到：看到x_n=f(f(...f(x_0)))或多次复合
- 应想到：想到固定点与函数迭代稳定性。
- 第一动作：先找固定点，再看导数绝对值、单调性、区间映射
- 动作链：先找固定点，再看导数绝对值、单调性、区间映射。
- 断点提醒：复合极限不一定等于简单函数极限。
- 错因倾向：目标识别断点 / 方法论调取失败

### H02-008｜双通项
- 来源页：p13-21
- 看到：看到a_n,b_n相互递推
- 应想到：想到向量化或和差化。
- 第一动作：把(a_n,b_n)^T写成矩阵递推，或构造s_n=a_n+b_n、d_n=a_n-b_n解耦
- 动作链：把(a_n,b_n)^T写成矩阵递推，或构造s_n=a_n+b_n、d_n=a_n-b_n解耦。
- 断点提醒：如果线性递推，优先矩阵/特征值；如果非线性，优先不变量。
- 错因倾向：目标识别断点 / 方法论调取失败

## 第3讲 一元函数微分学的概念

### H03-001｜微分/一阶泰勒
- 来源页：p22-31
- 看到：看到f(x)-f(x0)、Δx、o(Δx)
- 应想到：想到一阶泰勒/微分定义。
- 第一动作：写f(x)-f(x0)=f'(x0)(x-x0)+o(x-x0)，用系数匹配求导数或极限
