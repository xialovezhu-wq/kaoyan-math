## 第3讲 矩阵运算

### L03-001｜矩阵乘法形状
- 来源页：p13-39
- 看到：看到矩阵乘法
- 应想到：先检查形状，识别内积/外积/复制/求和。
- 第一动作：列×行是秩1矩阵
- 动作链：列×行是秩1矩阵；行×列是内积；A=[列]时AB是列线性组合。
- 断点提醒：形状判断能避免大量盲算。
- 错因倾向：目标识别断点 / 方法论调取失败

### L03-002｜秩1矩阵幂
- 来源页：p13-39
- 看到：A=αβ^T或r(A)=1且A²=kA
- 应想到：想到A^n=k^{n-1}A。
- 第一动作：先算tr(A)或β^Tα得到k，再写幂
- 动作链：先算tr(A)或β^Tα得到k，再写幂。
- 断点提醒：若k=0要单独处理。
- 错因倾向：条件检查遗漏 / 动作链断裂

### L03-003｜试算找规律
- 来源页：p13-39
- 看到：求A^n且A低阶具体
- 应想到：先算A²/A³找关系。
- 第一动作：若A满足二次多项式，递推化简
- 动作链：若A满足二次多项式，递推化简；若周期，按模分类。
- 断点提醒：不要连续乘到n。
- 错因倾向：方法论调取失败 / 动作链断裂

### L03-004｜A=B+C拆分
- 来源页：p13-39
- 看到：A可以拆成简单矩阵和幂零/投影
- 应想到：考虑二项式简化。
- 第一动作：若B=E，用(I+C)^n
- 动作链：若B=E，用(I+C)^n；若BC=CB=0，则(A)^n=B^n+C^n；若C幂零截断。
- 断点提醒：需检查可交换或乘积为0。
- 错因倾向：方法论调取失败 / 动作链断裂

### L03-005｜相似求幂
- 来源页：p13-39
- 看到：A可相似对角化或已给P^{-1}AP
- 应想到：用A^n=PΛ^nP^{-1}。
- 第一动作：找特征值/特征向量组成P
- 动作链：找特征值/特征向量组成P；或直接用已给相似关系。
- 断点提醒：P列顺序必须与Λ对角顺序对应。
- 错因倾向：方法论调取失败 / 动作链断裂

### L03-006｜伴随矩阵
- 来源页：p13-39
- 看到：看到A^*
- 应想到：先问A是否可逆。
- 第一动作：可逆：A^*=|A|A^{-1}
- 动作链：可逆：A^*=|A|A^{-1}；不可逆按秩分情况；还可用AA^*=|A|E。
- 断点提醒：伴随矩阵秩与A秩关系常考。
- 错因倾向：目标识别断点 / 方法论调取失败

### L03-007｜逆矩阵
- 来源页：p13-39
- 看到：求A^{-1}或证明可逆
- 应想到：多入口：定义、行列式、初等变换、特征值0、伴随矩阵。
- 第一动作：具体矩阵用[A|E]初等行变换
- 动作链：具体矩阵用[A|E]初等行变换；抽象矩阵用构造AB=E或多项式。
- 断点提醒：方阵才谈可逆。
- 错因倾向：条件检查遗漏 / 动作链断裂

### L03-008｜初等矩阵
- 来源页：p13-39
- 看到：出现初等变换/左乘右乘
- 应想到：左乘做行变换，右乘做列变换。
- 第一动作：把变换序列写成初等矩阵乘积
- 动作链：把变换序列写成初等矩阵乘积；求P,Q使PAQ为标准形。
- 断点提醒：行列混用要看任务是否允许。
- 错因倾向：方法论调取失败 / 动作链断裂

### L03-009｜分块矩阵
- 来源页：p13-39
- 看到：矩阵有大块零、单位块、对角块
- 应想到：用分块运算。
- 第一动作：按块加减乘转置
- 动作链：按块加减乘转置；分块对角矩阵的幂/逆逐块处理。
- 断点提醒：块乘法仍要满足形状匹配。
- 错因倾向：方法论调取失败 / 动作链断裂

### L03-010｜AB=0
- 来源页：p13-39
- 看到：看到矩阵乘积为0
- 应想到：翻译为A作用在B的每一列为0。
- 第一动作：B的列向量属于Ax=0解空间
- 动作链：B的列向量属于Ax=0解空间；用秩/维数判断。
- 断点提醒：AB=0不意味着A=0或B=0。
- 错因倾向：目标识别断点 / 方法论调取失败

### L03-011｜矩阵方程
- 来源页：p13-39
- 看到：AX=B、XA=B、AXB=C等
- 应想到：先化简、提公因式、看可逆/满秩。
- 第一动作：可逆时直接左/右乘逆
- 动作链：可逆时直接左/右乘逆；不可逆时按列分块转方程组；抽象时设X=(x_ij)。
- 断点提醒：左右乘不能交换。
- 错因倾向：方法论调取失败 / 动作链断裂

### L03-012｜消公因式
- 来源页：p13-39
- 看到：CA=CB或AC=BC
- 应想到：若C可逆或满秩，可消。
- 第一动作：C列满秩可由CA=CB推出A=B
- 动作链：C列满秩可由CA=CB推出A=B；C行满秩可由AC=BC推出A=B。
- 断点提醒：不是任意矩阵都能消。
- 错因倾向：条件检查遗漏 / 动作链断裂

### L03-013｜难题找实际考点
- 来源页：p13-39
- 看到：题面新但条件如B²=A、AB=BA
- 应想到：透过形式找背后知识点。
- 第一动作：对照知识结构：矩阵幂、相似、可逆、秩、特征值
- 动作链：对照知识结构：矩阵幂、相似、可逆、秩、特征值；尝试从给定等式左右乘得到新关系。
- 断点提醒：不要被“新题型”吓住，本质仍是标准对象。
- 错因倾向：条件检查遗漏 / 动作链断裂

## 第4讲 矩阵的秩

### L04-001｜秩定义
- 来源页：p40-47
- 看到：求矩阵秩
- 应想到：具体矩阵用初等变换，抽象矩阵用公式。
- 第一动作：化为行阶梯形，非零行数为秩
- 动作链：化为行阶梯形，非零行数为秩；或找最大非零子式。
- 断点提醒：初等行/列变换不改变秩。
- 错因倾向：条件检查遗漏 / 动作链断裂

### L04-002｜满秩乘积
- 来源页：p40-47
- 看到：AB中A列满秩或B行满秩
- 应想到：秩可穿透。
- 第一动作：若A列满秩，r(AB)=r(B)
- 动作链：若A列满秩，r(AB)=r(B)；若B行满秩，r(AB)=r(A)。
- 断点提醒：先检查中间维数满秩。
- 错因倾向：条件检查遗漏 / 动作链断裂

### L04-003｜AB/ABC秩不等式
- 来源页：p40-47
- 看到：看到乘积秩估计
- 应想到：想到Sylvester不等式和单调性。
- 第一动作：r(AB)≤min
- 动作链：r(AB)≤min；r(AB)≥r(A)+r(B)-n；ABC用r(ABC)≥r(AB)+r(BC)-r(B)。
- 断点提醒：维数n是中间维。
- 错因倾向：条件检查遗漏 / 动作链断裂

### L04-004｜和的秩
- 来源页：p40-47
- 看到：看到A+B或A-B
- 应想到：用拼接矩阵估计。
- 第一动作：r(A+B)≤r([A,B])≤r(A)+r(B)，并可得|r(A)-r(B)|≤r(A-B)
- 动作链：r(A+B)≤r([A,B])≤r(A)+r(B)，并可得|r(A)-r(B)|≤r(A-B)。
- 断点提醒：同型矩阵才可相加。
- 错因倾向：条件检查遗漏 / 动作链断裂

### L04-005｜A^T A
- 来源页：p40-47
- 看到：出现A^T A或AA^T
- 应想到：想到与A同秩、同解空间关系。
- 第一动作：r(A)=r(A^T)=r(A^T A)=r(AA^T)
- 动作链：r(A)=r(A^T)=r(A^T A)=r(AA^T)。
- 断点提醒：实矩阵背景下使用。
- 错因倾向：方法论调取失败 / 动作链断裂

### L04-006｜伴随矩阵秩
- 来源页：p40-47
- 看到：看到r(A^*)
- 应想到：按r(A)分情况。
- 第一动作：n阶A：r(A)=n则r(A^*)=n
- 动作链：n阶A：r(A)=n则r(A^*)=n；r(A)=n-1则r(A^*)=1；r(A)<n-1则r(A^*)=0。
- 断点提醒：不要套A^*=|A|A^{-1}到不可逆情形。
- 错因倾向：条件检查遗漏 / 动作链断裂

### L04-007｜方程组与秩
- 来源页：p40-47
- 看到：Ax=0基础解系个数
- 应想到：用n-r(A)。
- 第一动作：齐次解空间维数=n-r(A)
- 动作链：齐次解空间维数=n-r(A)；同解问题看秩与拼接秩。
- 断点提醒：未知数个数n不是方程数m。
