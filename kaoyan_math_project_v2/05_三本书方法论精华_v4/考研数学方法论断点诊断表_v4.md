# 考研数学方法论断点诊断表_v4

用途：把“做不出来”的原因定位到具体动作断点。GPT 讲错题时先用本表判断，不要直接归咎为计算粗心。

## 总判定

1. 目标 O 没锁定：目标识别断点。
2. 题面信号没看到：触发信息遗漏。
3. 信号看到了但没想到方法：方法论调取失败。
4. 方法想到了但第一动作没做：动作链断裂。
5. 忘了定义域、端点、秩、可逆、正定、收敛域、单调性、区域边界：条件检查遗漏。
6. 都做了但算错：计算细节错误。

## 高频断点到方法卡

| 断点类型 | 常见表现 | 应回查方法卡 | 下次提醒 |
|---|---|---|---|
| 目标识别断点 | 题目很长，直接开始算 | H00-001 | 先写目标 O：求、证、判、求参、分类还是求范围 |
| 触发信息遗漏 | 看到关键词但没把它当入口 | H00-005, H00-006 | 先把题面信号翻译成动作 |
| 方法论调取失败 | 知识会但考场没想到 | H00-007, H00-008 | 问它能否化归成见过的基本型 |
| 动作链断裂 | 方向对，但第一步没做 | H01-001, H16-001, L05-001 | 按卡片第一动作先做前置检查 |
| 条件检查遗漏 | 公式用了但条件没查 | H08-005, H16-008, L08-002, L09-009 | 查端点、定义域、秩、正定、收敛域 |
| 分类讨论遗漏 | 参数、端点、符号、重根没分类 | H01-010, H06-009, L05-003 | 先列分类依据再计算 |
| 收尾验证遗漏 | 算出结果没回代/没验端点 | H16-020, L05-002, L09-009 | 最后回到题目问法验证 |
