# 考研数学错因分类_动作断点表

用途：给模式 A 的“错因归纳”和 Codex 历史错题更新使用。核心不是问“知识会不会”，而是定位“题面信号 → 方法论 → 动作链”的哪一环断掉。

## 一、总判定树

1. 题目目标 O 是否锁定？
   - 没锁定：目标识别断点。
   - 锁定了：继续看触发信息。
2. 题面触发信息是否被识别？
   - 没识别：触发信息遗漏。
   - 识别了：继续看方法论。
3. 是否调用了对应方法论？
   - 没调用：方法论调取失败，即“知识懂了但没想到”。
   - 调用了：继续看动作链。
4. 动作链是否完整执行？
   - 少了前置检查、分类、端点、定义域、秩、收敛域、回代：动作链断裂/条件检查遗漏。
   - 全做了但计算错：计算细节错误。

## 二、错因类型表

| 错因类型 | 判断标准 | 典型句式 | Codex 记录字段 |
|---|---|---|---|
| 知识缺口 | 不知道公式、定理、定义，或使用条件完全不清 | 你这里确实缺的是“____”的定义/定理条件 | knowledge_gap |
| 目标识别断点 | 不知道题目是在求、证、判、分类、求参、求范围还是判敛 | 这题真正目标是“____”，你一开始没有先锁定它 | target_O_break |
| 触发信息遗漏 | 题面已出现关键词/结构，但没有注意 | 看到“____”时，本应把它当成触发信号 | trigger_miss |
| 方法论调取失败 | 知识懂，但考场没有想到该方法 | 你不是不会“____”，而是没有把“____”翻译成“____” | method_recall_fail |
| 动作链断裂 | 想到方向，但少了第一动作/关键动作 | 你方向对，但动作链少了“____” | action_chain_break |
| 条件检查遗漏 | 公式会用，但忘记定义域、端点、收敛域、秩、正项、单调、可逆、独立性等 | 你用了“____”，但漏查条件“____” | condition_check_miss |
| 分类讨论遗漏 | 参数、符号、根、端点、区域分块等没有分类 | 这里必须按“____”分类，否则结论不全 | classification_miss |
| 收尾验证遗漏 | 没有回代、验根、验端点、验范围、验题目问法 | 计算结束后还要验证“____” | final_check_miss |
| 计算细节错误 | 方法与动作都对，但代数、符号、积分、行变换、求导错误 | 主要问题不是入口，而是“____”处计算失误 | calculation_error |

## 三、动作断点练习表

| 看到什么 | 应先做什么 | 最常见断点 | 下次提醒句 |
|---|---|---|---|
| 看到 \(\sum u_n\) 判敛 | 先算 \(\lim u_n\) | 直接套判别法，跳过必要条件 | 看到级数判敛，先查通项极限 |
| 看到幂级数 | 先求收敛半径/收敛区间，再查端点 | 只求半径，不查端点 | 看到幂级数，端点必须单独判 |
| 看到 \(1^\infty\) | 取对数，转为 \(v\ln u\) | 直接代成 1 | 看到幂指未定式，先对数化 |
| 看到分段点/绝对值点 | 左右极限/左右导数分开 | 只算一侧或直接套公式 | 看到分段点，左右分开算 |
| 看到根的个数 | 零点定理证存在，罗尔/导数控个数 | 只证存在不证唯一/个数 | 根数题：存在性和个数上界分开做 |
| 看到反常积分 | 先找全部反常点 | 漏瑕点或无穷远 | 反常积分先列反常点 |
| 看到二重极限不存在 | 试特殊路径，同阶再变阶 | 用一条路径就判存在 | 二重极限存在要统一，不存在找路径 |
| 看到二重积分换序 | 先画区域再写新限 | 不画图直接换序 | 换序先画区域 |
| 看到矩阵秩 | 先看矩阵形状、行列式、初等变换、分块 | 盲目算完不解释 | 秩题先选最快判秩入口 |
| 看到齐次方程组 | 看未知数个数 n 与秩 r | 不用 n-r 判断解空间维数 | 齐次解空间维数是 n-r |
| 看到非齐次方程组 | 先判相容：r(A)=r(A,b) | 直接求解不判相容 | 非齐次先看增广秩 |
| 看到相似/对角化 | 先看特征值、特征向量维数 | 只算特征值不判向量数 | 对角化看每个特征值的几何重数 |
| 看到 \(f(A)\) | 想到特征值映射 \(f(\lambda)\) 或最小多项式 | 硬算矩阵多项式 | 看到 f(A)，先看特征值怎么变 |
| 看到正定二次型 | 顺序主子式/合同标准形/特征值全正 | 只看对角元素 | 正定不是看对角，先选判别法 |

## 四、模式 A 错因句式模板

- 你这一步“____”是对的，说明你已经识别出“____”。
- 真正断掉的是：看到“____”后，没有触发“____”这张方法卡。
- 本质不是知识点完全不会，而是“题面信号 → 方法论 → 第一动作”的链条没有合上。
- 下次看到同类结构，第一反应先做“____”，再进入计算。
