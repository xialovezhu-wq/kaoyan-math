# 题目 28-3（ID: 57921）

## 题目主题

过一点且与两平面交线垂直的平面方程

## 题目原图

![题目原图](images/28-3_question.png)

## 题面文本

过点 \((2,0,-3)\)，且与直线
\[
\begin{cases}
x-2y+4z-7=0,\\
3x+5y-2z+1=0
\end{cases}
\]
垂直的平面方程为________。

## 标准答案

\(16x-14y-11z-65=0\)

## 解析图

### 解析原图（分段展示）

![解析原图（分段展示）](images/28-3_solution_part1.png)

![解析原图（分段展示）](images/28-3_solution_part2.png)

## 涉及知识点

- 空间直线由两个平面的交线给出时，直线方向向量可由两个平面法向量叉乘得到。
- 平面与直线垂直时，平面的法向量与直线方向向量平行。
- 平面点法式：已知法向量 (A,B,C) 和平面上一点 (x0,y0,z0)，写 A(x-x0)+B(y-y0)+C(z-z0)=0。
- 法向量只表示方向，乘任意非零常数仍是同一法向方向；平面方程整体乘非零常数表示同一平面。
- 核心机制：平面内向量与法向量垂直，故点积为 0。

## 本题学习断点

已正确求出直线方向向量和平面法向量；第一个真实断点是不会由“法向量 + 平面上一点”写出平面点法式。

## 完整对话记录

### 对话 1｜用户

在这道题中，我通过这条直线的两个平面方程，确实得到了直线的方向向量，从而求出了平面的法向量。

我的问题是：在已知平面的法向量和平面上的一点时，我该怎么求出这个平面的方程？这块基础知识我有些欠缺，你帮我看看具体该怎么求。

至于平面的法向量，我算出来是没问题的。

### 对话 2｜助手

对，你前面的思路是对的：**直线方向向量已经求出，因此与该直线垂直的平面的法向量也已经确定。**你现在缺的只是最后一个基础动作：

> **已知平面上一点 + 平面法向量，如何写平面方程。**

这就是平面的**点法式方程**。

### 你只需要记住这个公式

若平面经过

\[
P_0(x_0,y_0,z_0)
\]

并且法向量为

\[
\boldsymbol n=(A,B,C),
\]

那么平面方程直接写成

\[
\boxed{
A(x-x_0)+B(y-y_0)+C(z-z_0)=0
}
\]

它叫**平面的点法式方程**。

---

### 为什么一定是这个式子？

假设平面上任取一个点

\[
P(x,y,z).
\]

那么从已知点 \(P_0\) 指向 \(P\) 的向量是

\[
\overrightarrow{P_0P}
=
(x-x_0,\ y-y_0,\ z-z_0).
\]

注意：

- \(\overrightarrow{P_0P}\) **躺在平面内**；
- \(\boldsymbol n\) 是平面的**法向量**，也就是垂直于整个平面。

因此二者必然垂直：

\[
\boldsymbol n\cdot\overrightarrow{P_0P}=0.
\]

于是

\[
(A,B,C)\cdot
(x-x_0,y-y_0,z-z_0)=0,
\]

展开就是

\[
\boxed{
A(x-x_0)+B(y-y_0)+C(z-z_0)=0.
}
\]

所以这个公式其实不是硬背出来的，本质只有一句：

\[
\boxed{\text{法向量}\perp\text{平面内任意向量}
\Rightarrow
\text{点积}=0}
\]

---

## 放回你这道题

你已经算出一个法向量为

\[
\boldsymbol n=(-16,14,11),
\]

平面经过

\[
P_0=(2,0,-3).
\]

直接套点法式：

\[
-16(x-2)+14(y-0)+11\bigl(z-(-3)\bigr)=0.
\]

也就是

\[
-16(x-2)+14y+11(z+3)=0.
\]

展开：

\[
-16x+32+14y+11z+33=0,
\]

所以

\[
-16x+14y+11z+65=0.
\]

整个方程乘 \(-1\)：

\[
\boxed{16x-14y-11z-65=0}.
\]

这与标准答案一致。

---

### 你还可以用另一种方法理解

一般平面方程是

\[
Ax+By+Cz+D=0.
\]

它的法向量就是

\[
\boxed{(A,B,C)}.
\]

所以你一旦知道法向量

\[
(-16,14,11),
\]

其实平面已经可以先写成

\[
-16x+14y+11z+D=0.
\]

现在只剩下 \(D\) 不知道。

因为平面经过 \((2,0,-3)\)，把这个点代进去：

\[
-16(2)+14(0)+11(-3)+D=0,
\]

于是

\[
D=65.
\]

因此还是

\[
-16x+14y+11z+65=0.
\]

两种方法完全一样，只不过考试中我更建议你直接用**点法式**，更快、更不容易出错。

你现在只需要确认一个机制：**为什么平面上的任意点 \(P\) 与已知点 \(P_0\) 组成的向量 \(\overrightarrow{P_0P}\)，和法向量的点积一定等于 \(0\)？**

### 对话 3｜用户

好，那我这道题懂了，没问题了

### 对话 4｜助手

好，这道题可以收住了。

你只要留下这一条记忆即可：

\[
\boxed{\text{已知法向量 }(A,B,C)\text{ 和平面上一点 }(x_0,y_0,z_0)}
\]

立即写

\[
\boxed{A(x-x_0)+B(y-y_0)+C(z-z_0)=0}
\]

本质就是：

\[
\boxed{\text{法向量}\perp\text{平面内向量}\Rightarrow \text{点积}=0}
\]

这块基础补上之后，以后碰到“**过一点且垂直于某直线的平面**”这类题，后半段就可以直接完成。

# 题目 28-4（ID: 57969）

## 题目主题

点到平面的距离

## 题目原图

![题目原图](images/28-4_question.png)

## 题面文本

点 \(P(1,-1,2)\) 到平面
\[
\pi:2x-y+5z-12=0
\]
的距离 \(d=\underline{\qquad}\)。

## 标准答案

\(\dfrac{\sqrt{30}}{30}\)

## 解析图

### 解析图（按用户上传内容复刻）

![解析图（按用户上传内容复刻）](images/28-4_solution_recreated.png)

## 涉及知识点

- 点到平面的距离公式：d=|Ax0+By0+Cz0+D|/√(A²+B²+C²)。
- 分子是“点代入平面方程左端后的绝对值”；分母是平面法向量 (A,B,C) 的模。
- 两点距离：对应坐标作差、平方、相加、开根号。
- 二维点到直线与三维点到空间直线必须区分：前者使用一般式代入公式，后者通常使用叉乘求高或参数最值。
- 距离必须非负，因此分子要取绝对值。

## 本题学习断点

遗忘了点到平面的距离公式，并把点到二维直线、点到空间直线、点到点距离混在一起，需要建立公式分类。

## 完整对话记录

### 对话 1｜用户

这道题我是点到平面的距离公式有点忘记了，包括点到直线的距离公式，还有点跟点之间的距离公式，我都有点忘记了，你都给我列举一下。

### 对话 2｜助手

可以，这几个距离公式建议你**放在一起记**。

## 1. 两点之间的距离

空间中两点

\[
P_1(x_1,y_1,z_1),\qquad P_2(x_2,y_2,z_2),
\]

则

\[
\boxed{
d=
\sqrt{
(x_2-x_1)^2+
(y_2-y_1)^2+
(z_2-z_1)^2
}
}
\]

二维平面中就是少一个 \(z\)：

\[
\boxed{
d=
\sqrt{
(x_2-x_1)^2+
(y_2-y_1)^2
}
}
\]

记忆：**坐标对应作差 → 平方 → 相加 → 开根号。**

---

## 2. 点到平面的距离

点

\[
P(x_0,y_0,z_0)
\]

到平面

\[
\pi:Ax+By+Cz+D=0
\]

的距离：

\[
\boxed{
d=
\frac{
|Ax_0+By_0+Cz_0+D|
}{
\sqrt{A^2+B^2+C^2}
}
}
\]

这个非常重要。

### 怎么记？

分子：

\[
\boxed{\text{把点的坐标直接代进平面方程左边，取绝对值}}
\]

分母：

\[
\boxed{\text{平面法向量 }(A,B,C)\text{ 的模}}
\]

也就是

\[
\sqrt{A^2+B^2+C^2}.
\]

例如你现在这道题：

\[
P(1,-1,2),
\]

\[
2x-y+5z-12=0,
\]

所以

\[
d=
\frac{|2(1)-(-1)+5(2)-12|}
{\sqrt{2^2+(-1)^2+5^2}}
=
\frac1{\sqrt{30}}.
\]

---

# 3. 点到直线的距离

这里要分成**二维直线**和**空间直线**。

### 二维：点到平面直线

若

\[
P(x_0,y_0)
\]

到直线

\[
Ax+By+C=0,
\]

则

\[
\boxed{
d=
\frac{|Ax_0+By_0+C|}
{\sqrt{A^2+B^2}}
}
\]

你会发现它和刚才的点到平面公式长得几乎一模一样。

实际上可以一起记：

\[
\boxed{
\frac{\left|\text{点代入方程左端}\right|}
{\left|\text{法向量}\right|}
}
\]

二维直线法向量是

\[
(A,B),
\]

三维平面法向量是

\[
(A,B,C).
\]

---

### 三维：空间中的点到直线

这是你现在这一章更需要注意的。

空间直线 \(L\) 上取一点

\[
A(x_1,y_1,z_1),
\]

直线的方向向量为

\[
\boldsymbol s=(l,m,n).
\]

空间中另有一点 \(P\)。

先构造

\[
\overrightarrow{AP}.
\]

则点 \(P\) 到直线 \(L\) 的距离：

\[
\boxed{
d=
\frac{
\left\|
\overrightarrow{AP}\times \boldsymbol s
\right\|
}{
\|\boldsymbol s\|
}
}
\]

这个公式建议你**不要纯硬背**。

因为

\[
\left\|
\overrightarrow{AP}\times \boldsymbol s
\right\|
\]

表示以 \(\overrightarrow{AP}\) 和 \(\boldsymbol s\) 为邻边的平行四边形面积。

而

\[
\text{面积}=\text{底}\times\text{高}.
\]

这里：

\[
\text{底}=\|\boldsymbol s\|,
\]

“高”恰好就是**点到直线的距离** \(d\)。

所以

\[
\|\overrightarrow{AP}\times\boldsymbol s\|
=
\|\boldsymbol s\|d,
\]

自然得到

\[
\boxed{
d=
\frac{\|\overrightarrow{AP}\times\boldsymbol s\|}
{\|\boldsymbol s\|}
}.
\]

---

## 你现在先把这张“小表”记住

| 距离 | 公式 |
|---|---|
| **点—点** | \(\displaystyle d=\sqrt{(\Delta x)^2+(\Delta y)^2+(\Delta z)^2}\) |
| **点—平面** | \(\displaystyle d=\frac{|Ax_0+By_0+Cz_0+D|}{\sqrt{A^2+B^2+C^2}}\) |
| **点—二维直线** | \(\displaystyle d=\frac{|Ax_0+By_0+C|}{\sqrt{A^2+B^2}}\) |
| **点—空间直线** | \(\displaystyle d=\frac{\|\overrightarrow{AP}\times\boldsymbol s\|}{\|\boldsymbol s\|}\) |

最值得区分的是最后两个：

\[
\boxed{\text{二维点到直线：代公式}}
\]

\[
\boxed{\text{空间点到直线：叉乘求高}}
\]

而你当前这道题属于第二种：

\[
\boxed{\text{点到平面}=
\frac{|\text{代入平面左端}|}{|\text{法向量}|}}
\]

这几个公式先记到这个程度就够用了。

## 题目主题

L : \frac{x}{3}=\frac{y}{3}=\frac{z+1}{2}

## 标准答案

### 解析图 B：按较早上传内容复刻的叉乘法

## 涉及知识点

- 空间直线对称式 (x-a)/m=(y-b)/n=(z-c)/p 可转为参数式 x=a+mt, y=b+nt, z=c+pt。
- 对称式分母 (m,n,p) 是方向向量，不是唯一法向量；令 t=0 可快速取直线上一点。
- 点到空间直线距离公式：d=‖P0P×s‖/‖s‖，本质是平行四边形面积除以底边长度。
- 另一条路线：把直线上任意点参数化为 Q(t)，利用点到直线距离 = min PQ。
- 因为 PQ≥0，平方函数在非负区间严格递增，所以最小化 PQ 与最小化 PQ² 的取值位置相同；最终距离需对 min(PQ²) 开根号。
- 二次式 at²+bt+c 配方：先提 a，再对括号内一次项做“半系数平方”。
- 本题 PQ²=22t²-4t+3=22(t-1/11)²+31/11，故 t=1/11 时最小。

## 本题学习断点

用户已正确把对称式转成参数式；第一个真实断点是把 (3,3,2) 误认成法向量，并试图把空间直线强行写成二维一般式 Ax+By+C=0。随后又补齐了参数最值、平方单调性和非首一二次式配方。

### 对话 2｜助手

你其实**已经起步成功了**。你写出的参数式完全正确。真正的第一个断点有两个：

1. \((3,3,2)\) 是这条空间直线的**方向向量**，不是法向量；
2. 不需要把空间直线强行变成 \(Ax+By+C=0\)。后者是二维平面中的直线形式，而在三维空间中，一个一次方程通常表示的是**平面**。

## 一、你得到的参数式已经是直线方程

原直线为

\[
\frac{x}{3}=\frac{y}{3}=\frac{z+1}{2}.
\]

令它们都等于 \(t\)：

\[
\frac{x}{3}=\frac{y}{3}=\frac{z+1}{2}=t,
\]

则

\[
x=3t,\qquad y=3t,\qquad z=2t-1.
\]

把它合在一起写：

\[
\boxed{
(x,y,z)=(0,0,-1)+t(3,3,2)
}
\]

这句话同时告诉了我们两件事：

\[
\boxed{P_0=(0,0,-1)}
\]

是直线上的一个点；

\[
\boxed{\boldsymbol s=(3,3,2)}
\]

是直线的方向向量。

也可以直接令 \(t=0\)，得到直线上的点

\[
P_0=(0,0,-1).
\]

所以你并不需要再“构造一个直线方程”。**你写出的参数式本身就是直线方程。**

---

## 二、为什么 \((3,3,2)\) 不是法向量？

对于空间直线

\[
\frac{x-x_0}{l}
=
\frac{y-y_0}{m}
=
\frac{z-z_0}{n},
\]

分母构成的是方向向量：

\[
\boxed{\boldsymbol s=(l,m,n)}.
\]

因此本题中

\[
\boldsymbol s=(3,3,2).
\]

空间直线不像平面那样只有一个固定的法向方向。所有垂直于 \((3,3,2)\) 的向量，都可以说是这条直线的一个法向量，因此它的法向量并不唯一。

这里真正要使用的是：

\[
\boxed{\text{直线上的一点}+\text{直线的方向向量}}.
\]

# 三、直接使用点到空间直线的距离公式

已知直线上的点

\[
P_0=(0,0,-1),
\]

直线外的点

\[
P=(1,-1,0).
\]

先构造从直线上一点指向已知点的向量：

\[
\overrightarrow{P_0P}
=
P-P_0
=
(1-0,-1-0,0-(-1)).
\]

所以

\[
\overrightarrow{P_0P}=(1,-1,1).
\]

点到空间直线的距离公式是

\[
\boxed{
d=
\frac{
\left\|
\overrightarrow{P_0P}\times \boldsymbol s
\right\|
}{
\|\boldsymbol s\|
}
}.
\]

代入：

\[
d=
\frac{
\left\|
(1,-1,1)\times(3,3,2)
\right\|
}{
\sqrt{3^2+3^2+2^2}
}.
\]

计算叉乘：

\[
(1,-1,1)\times(3,3,2)
=
\begin{vmatrix}
\boldsymbol i&\boldsymbol j&\boldsymbol k\\
1&-1&1\\
3&3&2
\end{vmatrix}
=
(-5,1,6).
\]

因此

\[
d
=
\frac{\sqrt{(-5)^2+1^2+6^2}}
{\sqrt{3^2+3^2+2^2}}
=
\frac{\sqrt{62}}{\sqrt{22}}.
\]

化简为

\[
\boxed{
d=\frac{\sqrt{341}}{11}
}.
\]

---

## 四、你的参数式思路也可以直接继续

你已经得到直线上任意一点

\[
Q(t)=(3t,3t,2t-1).
\]

点 \(P\) 到直线距离最短时，\(Q\) 就是垂足，因此

\[
\overrightarrow{PQ}\perp \boldsymbol s.
\]

有

\[
\overrightarrow{PQ}
=
Q-P
=
(3t-1,3t+1,2t-1).
\]

利用垂直则点积为零：

\[
(3t-1,3t+1,2t-1)\cdot(3,3,2)=0.
\]

即

\[
3(3t-1)+3(3t+1)+2(2t-1)=0,
\]

得到

\[
22t-2=0,
\qquad
t=\frac1{11}.
\]

于是垂足为

\[
Q=
\left(
\frac3{11},
\frac3{11},
-\frac9{11}
\right).
\]

最后再利用两点距离公式计算 \(PQ\)，同样得到

\[
d=\frac{\sqrt{341}}{11}.
\]
