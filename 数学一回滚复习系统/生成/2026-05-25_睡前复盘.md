### B. 斜渐近线固定两步

```text
a = lim f(x)/x
b = lim [f(x)-ax]
```

不能只算斜率。遇到截距常数项，要特别小心：

- 根式差：优先有理化。
- 对数差：合并成 ln(1+u)。
- ∞·0：改写成分式或等价无穷小。
- 负无穷根式：先处理 |x|，例如 sqrt(4x^2+x) ~ -2x。

GS-500 57941 的截距已校正为：

```text
x -> +∞: y = 2(ln2)x + 1 + ln2/4
x -> -∞: y = -2(ln2)x - 1 - ln2/4
```

看到分段函数，先不急着求导：


### D. 参数方程别把 t 当 x

参数方程题最后答案必须回到 x：

```text
先在 t 上判导数符号
再用 x=x(t) 把临界 t 转成 x
```

二阶导公式必须写成：

```text
d²y/dx² = [d/dt(dy/dx)] / [dx/dt]
```

- GS-499 57905：把 t 区间误写成 x 区间，且二阶导公式入口错。
- GS-462 57838：今天已做对并删除，说明“二阶导要除以 dx/dt”这点已经纠正一次。
