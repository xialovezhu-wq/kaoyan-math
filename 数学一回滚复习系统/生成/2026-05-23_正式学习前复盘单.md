## 先背 4 个入口

### 1. 变号因子和不等式

看到要除以 \(x-1\)、\(a-b\)、含正负不定因子时，先停一下：

1. 分区间。
2. 判端点。
3. 再除或移项。
4. 最后用辅助函数判符号。

口令：

\[
\boxed{\text{不等号两边同除前，先判除数正负。}}
\]

### 2. 罗尔 / 柯西中值定理

看到“存在 \(\xi\)”不要先套定理名，先反看目标式：

1. 目标含 \(f,f'\)：找 \(\mu(x)f(x)\)。
2. 目标含 \(f'',f'\)：把 \(f'\) 当作未知函数。
3. 目标是分式比值：把它改写成两个函数的端点差比值。
4. 端点值相等后接罗尔定理。

口令：

\[
\boxed{\text{目标式是什么导数，辅助函数就反推成什么。}}
\]

### 3. 递推数列

看到 \(x_{n+1}=f(x_n)\)，不要直接设极限：

1. 先证区间不变性。
2. 再证单调性。
3. 再由单调有界推出极限存在。
4. 最后代回递推式。

口令：

\[
\boxed{\text{唯一根只是候选极限，不是极限存在证明。}}
\]

### 4. 正项级数 / 等价比较

用比较、等价、p 级数前，先补三件事：

1. 通项是否最终为正。
2. 小量是否趋零。
3. 参数边界是否单独处理。

口令：

\[
\boxed{\text{比较判别先补前置条件，再比较主阶。}}
\]

### A2. GS-488 57892 指数因子罗尔 2026-05-22

已做 1 遍：2026-05-22。

任务：只练第二问，把 \(f'\) 当作未知函数。

必须写出：

\[
F(x)=e^{-\lambda x}f'(x)
\]

\[
F'(x)=e^{-\lambda x}\bigl(f''(x)-\lambda f'(x)\bigr)

所以目标 \(f''(\eta)-\lambda f'(\eta)=0\) 就是 \(F'(\eta)=0\)。

完成后评分：`MATH1-GS-WQ-GS488`
