# 方法论库

本目录保存考研数学方法论资料，用作 Codex 数学错题网络的底层参考库。

## 用途

- 方法论库不是错题解析，不保存具体错题的完整题干、长解析或作答痕迹。
- 方法论库用于支持后续错题卡中的 `method_gap`、`action_gap_type`、`method_trigger` 和 `related_method_card_id` 等字段匹配。
- `method_gap` 是错题卡中的解题方法断点层，用于记录“看到什么题面信号 -> 本应想到什么方法 -> 第一动作该做什么 -> 实际漏掉什么动作 -> 下次如何提醒”。
- `method_gap` 不替代 `wrong_point`、`error_causes`、`methods`、`traps`，只补充“知识学过但方法没有触发”或“动作链没有执行完整”的信息。
- 错题卡只引用 `related_method_card_id`，不复制整张方法卡内容。
- Codex 后续迁移历史错题时，必须优先查询本方法论库，再决定是否写入方法断点字段。
- 如果找不到对应方法卡，写 `related_method_card_id: 待匹配`，不得自动乱造方法卡 ID。

## 目录

- `方法卡/`：保存方法论卡片库 Markdown 与 JSON，作为方法卡 ID 和卡片内容的主来源。
- `映射表/`：保存题面触发词到方法卡 ID 的映射表。
- `错因分类/`：保存知识缺口、目标断点、触发遗漏、方法调取失败、动作链断裂等错因分类规则。
- `method_card_registry.md`：统一登记已导入的方法卡 ID 范围、命名规则和引用规范。
- `method_gap_schema.md`：统一记录 `method_gap` 标准字段、允许值、示例、禁止写法和校验规则。

## 引用规则

新增或迁移错题卡时，只允许在错题卡中记录方法卡引用，例如：

```yaml
related_method_card_id: H16-001
```

如果暂时无法确认对应方法卡，应写：

```yaml
related_method_card_id: 待匹配
```

不要把方法卡全文复制到错题卡；错题卡只保留本题的具体错点、触发信息、漏掉动作和下次提醒句。

## method_gap 写入原则

新增错题时，先判断错因属于哪一类：

- A 类：知识点不熟，确实不知道定义、公式、定理、性质或适用条件。
- B 类：解题方法没触发，知识可能学过，但实战时没有从题面信号调出方法，或动作链没有执行完整。
- A+B 混合：同时存在知识缺口和方法断点，应写 `knowledge_gap_or_method_gap: A+B混合`。

如果错在“看得懂答案，但自己做时没想到入口”，优先检查是否属于 `B2-TRIGGER`、`B3-METHOD`、`B4-CHAIN`，不要直接归为“知识点不熟”。

标准 schema、允许值和示例见：

```text
错题知识网络/方法论库/method_gap_schema.md
```
