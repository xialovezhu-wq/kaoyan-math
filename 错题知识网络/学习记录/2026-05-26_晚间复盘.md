## 2. 今天新增入库

今天新增 5 道无穷级数错题：

1. `GS-501 19516 交错级数有理化拆项`
   - 错点：看到 \((-1)^n\) 就想直接套莱布尼茨，没有先检查正项部分是否单调递减。
   - 入口：分母也含 \((-1)^n\)，先有理化拆成“收敛交错部分 - 发散调和部分”。

2. `GS-502 102347 条件收敛奇偶拆分`
   - 错点：知道是级数判敛散，但没有把 \(u_{2n}-2u_{2n-1}\) 拆开。
   - 入口：条件收敛先翻译成“原交错级数收敛、正项级数发散”，再做奇偶项拆分。

3. `GS-503 78385 有界因子望远镜绝对收敛`
   - 错点：看到 \(\sin(n+k)\) 先想交错，没有先取绝对值。
   - 入口：\(|\sin(n+k)|\le1\)，把整个通项压到收敛的望远镜级数。

4. `GS-504 102355 乘积配项绝对收敛`
   - 错点：条件收敛定义记反，并且没有围绕 \(\sum nu_n\) 绝对收敛构造目标项。
   - 入口：
     \[
     u_nv_n=(nu_n)\frac{v_n}{n}.
     \]

5. `GS-505 30185 交错p级数条件收敛范围`
   - 错点：只判断绝对值级数发散，漏掉原交错级数收敛条件。
   - 入口：
     \[
     \frac{\sqrt{n+1}-\sqrt n}{n^p}\sim\frac1{2n^{p+\frac12}},
     \]
     条件收敛要求
     \[
     0<p+\frac12\le1.
     \]

## 4. 睡前只背这 6 条

### A. 条件收敛两条线

题目问条件收敛，草纸上必须先写：

```text
原级数收敛
绝对值级数发散
```

对应：`GS-502`、`GS-504`、`GS-505`。

### B. 交错级数不能只看符号

看到 \((-1)^n\)，先提取正项部分 \(a_n\)，再检查：

```text
a_n > 0
a_n -> 0
a_n 最终单调递减
```

对应：`GS-501`、`GS-496`、`GS-505`。

### C. 已知收敛级数就是比较对象

看到“已知 \(\sum v_n\) 收敛”，先想：

```text
目标通项能不能改造成 C_n * v_n？
```

对应：`GS-484`、`GS-494`、`GS-504`。

### D. 有界因子要和整个通项一起看

任意项级数含 \(\sin\)、\(\cos\) 时，先问能不能取绝对值：

```text
|有界因子| <= M
```

对应：`GS-503`。

### E. 根式差先有理化

看到：

```text
sqrt(n+1)-sqrt(n)
```

先写：

```text
1 / [sqrt(n+1)+sqrt(n)]
```

对应：`GS-505`，也能迁移到渐近线截距题。

### F. 水平渐近线不要漏

只要：

```text
lim y(x) = C
```

就有水平渐近线：

```text
y = C
```

对应：`GS-017`、`GS-500`。
