\[
\ln(n+1)\le 1+\frac12+\cdots+\frac1n\le 1+\ln n

\lim_{n\to\infty}\frac{1+\frac12+\cdots+\frac1n}{\ln n}=1

\[
\boxed{

}

\[
\boxed{
看到 }1+\frac12+\cdots+\frac1n\text{，想到 }\int\frac1x\,dx=\ln x
}
\]

### GS-331 167713 振荡积分估计

文件：[GS-331](../错题卡/GS-331_167713振荡积分估计.md)

题型：变限积分估计 + 整体换元 + 分部积分放缩。

标准结论：

\[
f(x)=\int_x^{x+1}\sin u^2\,du,\qquad x>0
\]

\[
\boxed{|f(x)|\le \frac1x}
\]

本题错点：

- 看到 \(\sin u^2\) 没有先整体换元 \(t=u^2\)。
- 直接用 \(|\sin u^2|\le1\) 只能得到粗估计，达不到 \(1/x\)。

下次触发句：

\[
\boxed{
\sin u^2,\cos u^2,e^{-u^2}\text{ 这类相位平方，先整体换元。}
}
\]

方法链：

\[
u^2=t
\Longrightarrow
\int \frac{\sin t}{2\sqrt t}\,dt
\Longrightarrow
\sin t\,dt=-d(\cos t)
\Longrightarrow
\text{分部积分}
\Longrightarrow
|\cos t|\le1
\]

复做关联：`GS-445`、`GS-243`、`GS-325`、`GS-341`、`GS-344`。

### GS-312 103059 反三角周期积分

\arcsin\text{ 的值域是 }\left[-\frac\pi2,\frac\pi2\right]
}
\]

\[
\boxed{
S(x)=\int_0^x f(t)\,dt,\ x\to+\infty\text{ 时，先查 }f\text{ 是否周期。}
}
\]

复做关联：`GS-445`、`GS-331`、`GS-326`、`GS-129`。

### GS-446 170721 递推数列单调有界

文件：[GS-446](../错题卡/GS-446_170721递推数列单调有界.md)

题型：函数性质 + 递推数列极限存在性。

标准结论：

\[
\lim_{n\to\infty}x_n=0
\]

本题错点：

- 已经能看出 \(f(x)>0\)，但没有把“证明极限存在”转成“证明单调有界”。
- 递推式中已经出现 \(x_{n+1}-x_n\)，却没有先解出差值判号。

关键一步：

\[
x_{n+1}-x_n=-\frac{f(x_n)}{f'(x_n)}<0
\]

再由 \(f''(x)>0\) 推出 \(f'(x)\) 递增，从而：

\[
f(x_n)=\int_0^{x_n}f'(t)\,dt<x_nf'(x_n)
\]

所以：

\[
x_{n+1}=x_n-\frac{f(x_n)}{f'(x_n)}>0
\]

下次触发句：

\[
\boxed{
\text{证明递推数列极限存在，先试单调有界。}
}
\]

复做关联：`GS-059`、`GS-444`、`GS-079`、`GS-066`、`GS-063`、`GS-071`。

### GS-447 58000 零点可导性判定

文件：[GS-447](../错题卡/GS-447_58000零点可导性判定.md)

题型：含绝对值函数在 \(x=0\) 处可导性判断。

标准答案：

\[
\boxed{D}
\]

本题错点：

- 把 B 选项 \(|x|\sin\sqrt{|x|}\) 看错、拆错。
- 看到 \(\frac{|x|}{x}\) 就过早判不可导，没有继续看它是否乘了趋于 0 的因子。
- 漏掉真正左右导数不同的是 D。

B 的关键：

\[
\frac{|x|\sin\sqrt{|x|}}{x}
=\frac{|x|}{x}\sin\sqrt{|x|}
\to0
\]

因为 \(\frac{|x|}{x}\) 有界，而 \(\sin\sqrt{|x|}\to0\)。

D 的关键：

\[
\frac{\cos\sqrt{|x|}-1}{x}
\sim
-\frac12\frac{|x|}{x}
\]

左右极限不同，所以不可导。

下次触发句：

\[
\boxed{
\frac{|x|}{x}\text{ 不收敛，但乘上 }o(1)\text{ 可能趋于 }0。
}
\]

复做关联：`GS-035`、`GS-100`、`GS-097`、`GS-092`、`GS-107`。

- 没有在连接点 \(x=b\) 分别列“连续”和“左右导数相等”。

关键方程：

a\sqrt b=\ln b

\]

\[
b=e^2,\qquad a=\frac2e
\]

下次触发句：

\[
\boxed{
\text{分段函数连接点可导，先连续，再左右导数相等。}

\]

### GS-035 103358 根号平方可导性

文件：[GS-035](../错题卡/GS-035_103358根号平方可导性.md)

题型：根号平方 + 绝对值尖点 + 连续可导判定。

复发情况：第 2 次错，已归档到 2026-05-13。

标准答案：

\[
\boxed{\text{在 }x=1\text{ 处连续，但不可导}}
\]

本题错点：

- 把 \(\sqrt{(x-1)^2}\) 错写成 \(x-1\)。
- 正确应为 \(|x-1|\)，因此函数是 \(e^{|x-1|}\)，在 \(x=1\) 处有尖点。

关键：

\[
\sqrt{x^2-2x+1}
=\sqrt{(x-1)^2}
=|x-1|
\]

\[
\frac{e^{|x-1|}-1}{x-1}
\sim
\frac{|x-1|}{x-1}
\]

左导数为 \(-1\)，右导数为 \(1\)，所以不可导。

下次触发句：

\[
\boxed{
\sqrt{u^2}=|u|\text{，不是 }u。
}
\]

复做关联：`GS-100`、`GS-447`、`GS-448`、`GS-095`、`GS-097`。

### GS-100 1000题B组3.9

文件：[GS-100](../错题卡/GS-100_1000题B组3.9.md)

题型：绝对值函数在零点处可导性判定。

复发情况：第 2 次错，已归档到 2026-05-13。

标准答案：

\[
\boxed{f'(a)=0}
\]

本题错点：

- 又一次忽略“在一点可导”必须要求左右导数相等。
- \(|f(x)|\) 在 \(f(a)=0\) 附近会因左右符号产生不同导数。

关键：

\[
f(a+h)=f'(a)h+o(h)
\]

\[
\frac{|f(a+h)|-|f(a)|}{h}
=\frac{|f'(a)h+o(h)|}{h}
\]

当 \(h\to0^+\) 时，差商趋于：

\[
|f'(a)|
\]

当 \(h\to0^-\) 时，差商趋于：

\[
-|f'(a)|
\]

要可导，必须：

\[
|f'(a)|=-|f'(a)|
\]

所以：

\[
f'(a)=0
\]

下次触发句：

\[
\boxed{
|f(x)|\text{ 在 }f(a)=0\text{ 处可导，会强迫 }f'(a)=0。
}
\]

复做关联：`GS-035`、`GS-447`、`GS-448`、`GS-095`、`GS-097`。

## 共性错因归纳

### 1. 条件没有先翻译成可操作语句

今天多道题都卡在“题目条件没有先翻译”：

- 单调递减没有翻译成 \(f(k+1)\le f(x)\le f(k)\)。
- \(f''>0\) 没有翻译成 \(f'\) 递增，再推出 \(f(x)<xf'(x)\)。
- 可导没有翻译成“连续 + 左右导数相等”。
- \(\arcsin\) 没有翻译成主值区间限制。

复盘动作：

\[
\boxed{
\text{看到条件，先问：它能转成什么不等式、等式或区间限制？}
}
\]

### 2. 特殊结构没有触发固定套路

今天需要建立的固定触发如下：

- \(1+\frac12+\cdots+\frac1n\)：调和和式，想到 \(\ln x\)。
- \(\sin u^2,\cos u^2\)：先整体换元 \(t=u^2\)。
- \(\arcsin(\sin x)\)：先查主值区间。
- \(\sqrt{u^2}\)：先写 \(|u|\)。
- \(|x|\) 在 0 点：用导数定义看左右差商。
- 分段函数连接点：连续 + 左右导数相等。
- 证明递推数列极限存在：单调有界准则。

### 3. 过早判断

典型是 `GS-447`：

\[
\frac{|x|}{x}
\]

本身不收敛，但如果乘上趋于 0 的因子，整体仍可能收敛。

复盘动作：

\[
\boxed{
\text{看到不收敛因子，先看它是否被无穷小压掉。}
}
\]

### 4. 左右导数问题反复出现

今天最需要强化的是这一条：

\[
\boxed{
\text{连续不等于可导；左右各有公式也不等于可导；左右导数相等才可导。}
}
\]

涉及题：

- `GS-100`：\(|f(x)|\) 在 \(f(a)=0\) 处可导。
- `GS-035`：\(e^{|x-1|}\) 在 \(x=1\) 处不可导。
- `GS-447`：\(\cos\sqrt{|x|}\) 在 \(x=0\) 处不可导。
- `GS-448`：分段函数在 \(x=b\) 处可导。
