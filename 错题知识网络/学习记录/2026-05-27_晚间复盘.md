## 1. 今天的主线

今天不是计算不会，而是几类题的第一入口选慢或选错：

1. 选项里有交叉乘，应该反推 \(\frac{f(x)}x\)，不是构造 \(xf(x)\)。
2. 给出高阶导数条件，应该用泰勒最低非零项，不要逐层导数保号。
3. “若……则必有……”型命题，先找反例排除，不要先硬证明。
4. 极限命题反例构造，要先移项看清 \(a_n\) 应该在 \(a\pm\frac1n\) 的哪一侧。
5. 洛必达不能反用；原函数比值极限不能反推出导数比值极限。

## 4. 今晚只背这 5 条

### A. 交叉乘先化商

看到：

```text
a f(x), x f(a), b f(x), x f(b)
```

先想：

```text
f(t) / t
```

对应：`GS-506｜ID57844｜2026-05-27 第1次错`。

### B. 洛必达不能反用

```text
lim f(x)/x^2 = 1
```

不能推出：

```text
lim f'(x)/x = 2
```

对应：`GS-507｜ID170727｜2026-05-27 第1次错`。

### C. 高阶导看最低非零项

```text
前 n-1 阶为 0，第 n 阶不为 0
```

第一反应：

```text
泰勒展开，看最低非零项
```

偶数阶正为极小，偶数阶负为极大。

对应：`GS-508｜ID58023｜2026-05-27 第1次错`。

### D. 必有命题先反例

看到：

```text
若 P，则必有 Q
```

先问：

```text
能不能找 P 真、Q 假的例子？
```

对应：`GS-509｜ID58085｜2026-05-27 第1次错`、`GS-040｜ID58061｜2026-05-27 第2次错`。

### E. 反例构造先移项

涉及 \(a_n\)、\(a\pm\frac1n\) 时，不要机械写构造式。

固定步骤：

```text
先移项
看要破坏哪一侧
再选 a_n = a + c/n 或 a_n = a - c/n
```

对应：`GS-040｜ID58061｜2026-05-27 第2次错`。
