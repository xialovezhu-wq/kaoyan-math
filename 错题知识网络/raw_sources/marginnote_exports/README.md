# MarginNote 4 原始导出包

本目录保存 MarginNote 4 导出的原始材料。原件只读，不由 AI 改写。

## 推荐首批导出

同一焦点分支 3-5 道题，尽量同时导出：

1. `导出到 OmniOutliner (.oo3)`：主结构输入，用于保留节点层级、标题、图片引用和子节点解析文字。
2. `导出到 MS Word(docx)`：辅助输入，用于快速预览文本层、校验顺序、抽取嵌入图片。
3. `导出脑图为 PDF 格式`：可选视觉校验，用于人工核对脑图整体结构。
4. `导出学习集备份`：raw 备份，只保存，不在第一版强行解析。

当前已验收的导出样本：

- `/Users/xiazhibin/Desktop/数学第一章/考研高数(2026-06-30-20-10-36).oo3/`
- `/Users/xiazhibin/Desktop/数学第一章/考研高数(2026-06-30-20-10-28).docx`

验收结论：`.oo3` 更适合作为主输入，`docx` 作为辅助校验即可。脑图 PDF 暂时不是必需。

## 文件命名

推荐格式：

```text
2026-06-30_MN4_高数_第一章_试点_3-5题.oo3
2026-06-30_MN4_高数_第一章_试点_3-5题.docx
2026-06-30_MN4_高数_第一章_试点_3-5题_脑图.pdf
2026-06-30_MN4_高数_第一章_试点_3-5题_学习集备份.mnbackup
```

如果 MarginNote 导出文件名固定，保留原名也可以；在 `可视化错题详情/index.md` 中登记清楚即可。大体积原件可以先保留在桌面或外部目录，只在索引中登记绝对路径，等确认批量策略后再决定是否复制进本目录。

## 处理原则

- 原始导出文件不修改。
- Codex 只从原件抽取副本图片、OCR 文本和详情页。
- 如果题号、节点标题或解析边界不清，标记 `待确认`，不猜。
- 只更新视觉详情层时，不运行 `wrongnet.py rebuild`。
