# 方法缺口与错因模式 (★★★)

#math #method-gap #error-pattern

## Overview Table

| Gap | Meaning | Repair action |
|---|---|---|
| B2-TRIGGER | 看见信号但没触发动作 | 给信号配第一动作。 |
| B3-METHOD | 知道方法名但不会落地 | 把方法名写成第一步。 |
| B4-CHAIN | 开始做但动作链中断 | 每步写理由和下一步。 |
| B5-CHECK | 算完不检查 | 回查条件、端点、定义域、符号。 |

## Error Patterns

| Pattern | Diagnostic question |
|---|---|
| 边界条件遗漏 | 有没有先列边界？ |
| 只看局部不看整体 | 有没有找到整体变量或结构中心？ |
| 方法选择错误 | 有没有先判型？ |
| 过程跳步 | 每步是否有理由？ |
| 题型识别失败 | 入口是否选错？ |

## Decision Flow

```text
错题复盘
  -> 错在触发、方法、动作链、检查还是计算
  -> 写一句具体 wrong_point
  -> 配一个复做第一动作
```

## Exam/Test Patterns

| Scenario/Keyword | Answer |
|---|---|
| 看到参数没停 | B2-TRIGGER。 |
| 会说分类讨论但不会分 | B3-METHOD。 |
| 分了但漏端点 | B4-CHAIN 或 B5-CHECK。 |
| 算完没验定义域 | B5-CHECK。 |
