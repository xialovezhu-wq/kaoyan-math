# 高数第一动作总览 (★★★)

#math #calculus

## Overview Table

| Topic | Key point |
|---|---|
| 条件边界 | 参数、端点、分段点先列清单。 |
| 极限与连续 | 先判型，再选工具。 |
| 微分学应用 | 先判断导数定义、函数形态或中值定理入口。 |
| 积分结构 | 先看区间、变量、换元、中心和反常点。 |
| 级数 | 先写通项、首项、下标、收敛区间、端点。 |
| 多元函数 | 先画点、方向、区域、边界和线性主部。 |

## Decision Flow

```text
题面信号
  -> 是否有边界/参数/端点
  -> 是否有结构中心/整体变量
  -> 是否需要判型
  -> 选择方法
  -> 回查条件
```

## Exam/Test Patterns

| Scenario/Keyword | Answer |
|---|---|
| 参数、端点、绝对值 | 先列边界，再分类。 |
| 换元积分 | 检查变量、上下限、微分、区间。 |
| 幂级数 | 半径后单独查端点。 |
| 可微 | 写定义和一阶线性主部。 |

> [!warning] 例外
> 如果题目已经明确给出完整分类，也仍要检查分类是否覆盖端点和定义域。
