# Quick Reference

#dashboard #math

## 高数第一动作 → [[高数第一动作总览]]

| Signal | First action |
|---|---|
| 参数、端点、绝对值、分段点 | 先列边界清单。 |
| 极限未定式 | 先判型，再选等价、泰勒、洛必达或主导项。 |
| 定积分换元 | 先检查变量、上下限、微分和区间合法性。 |
| 级数收敛域 | 先求半径，再单独检查端点。 |
| 多元可微 | 先写可微定义和一阶线性主部。 |

## 线代对象判型 → [[线代对象判型总览]]

| Signal | First action |
|---|---|
| 矩阵乘法 | 检查维数、顺序、可逆条件。 |
| 方程组 | 比较秩，写自由变量和解空间维数。 |
| 向量组 | 判对象是行向量还是列向量，再转秩或系数方程。 |
| 二次型 | 先写对称矩阵和目标标准形。 |

## 方法缺口 → [[方法缺口与错因模式]]

| Code | Meaning | Training target |
|---|---|---|
| B2-TRIGGER | 题面信号没有触发第一动作 | 看到信号先停顿。 |
| B3-METHOD | 方法名不能落成动作 | 写出第一步。 |
| B4-CHAIN | 动作链中断 | 每步写理由。 |
| B5-CHECK | 结果缺检查 | 回查边界、符号、定义域。 |

## Must-Know Patterns

- 条件边界：参数、端点、分段点、定义域、等号归属。
- 积分结构：区间、变量、中心、整体、反常点。
- 级数结构：通项、首项、下标、收敛区间、端点。
- 线代结构：对象类型、秩、自由变量、特征结构。
