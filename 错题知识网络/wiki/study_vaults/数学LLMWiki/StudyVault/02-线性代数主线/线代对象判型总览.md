# 线代对象判型总览 (★★★)

#math #linear-algebra

## Overview Table

| Topic | Key point |
|---|---|
| 矩阵运算 | 先检查维数、乘法顺序、可逆条件。 |
| 行列式与秩一扰动 | 看到 \(I+\alpha\alpha^{\mathrm T}\) 或 \(I+uv^{\mathrm T}\)，先识别单位阵加秩一外积。 |
| 线性方程组 | 先比较秩，写自由变量和解空间维数。 |
| 向量组 | 先判断行向量/列向量和线性相关对象。 |
| 二次型 | 先写对称矩阵，再判标准形、正定性或合同。 |

## Decision Flow

```text
题面对象
  -> 矩阵 / 方程组 / 向量组 / 二次型
  -> 维数或秩
  -> 自由变量或特征结构
  -> 目标形式
```

## Exam/Test Patterns

| Scenario/Keyword | Answer |
|---|---|
| \(I+\alpha\alpha^{\mathrm T}\) | 特征值平移或矩阵行列式引理。 |
| 齐次方程组 | 秩 + 自由变量个数。 |
| 非齐次方程组 | 系数矩阵秩 vs 增广矩阵秩。 |
| 线性相关 | 转成系数方程或秩判断。 |
| 二次型 | 写对称矩阵和目标。 |

> [!warning] 例外
> 线代计算不能只看数值形式，必须保留对象类型；行变换、列变换和相似/合同变换不能混用。
