# MATHWIKI-QUESTIONS-004 测试题候选台账

- 统计来源：`错题知识网络/可视化错题详情/manifest.json`，当前记录数 948。

## 状态机

| status | 含义 | 下一步 |
| --- | --- | --- |
| candidate | 已登记候选，但缺正式入库条件或人工确认 | 补用户错因、解析、正式编号或重连证据 |
| confirmed | 已确认题图/解析/编号归属，但尚未转正式卡 | 决定 formal、dropped 或仅保留来源 |
| formal | 已转正式错题卡 | wrongnet rebuild 与质量门 |
| in-rollback | 已纳入回滚复习 | 只能按 scheduler/项目规则更新 |
| tutor-test | 只进入 Tutor 安全训练 | 不反写正式卡或回滚 JSON |
| mastered-spot-check | 已掌握抽查池 | 只用于抽检，不改掌握度 |
| dropped | 已确认不再作为正式候选推进 | 保留来源证据或关闭候选 |
