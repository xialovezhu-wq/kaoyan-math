### 陷阱

- \(|x-t|\) 的分段点是 \(t=x\)，应先放到 \(t\) 轴上，而不是把 \(x\) 与 \(t\) 混在同一套范围里乱分。
- 固定积分区间是 \(0\le t\le \pi/2\)：当 \(x<0\) 或 \(x>\pi/2\) 时不跨分段点，只有 \(0<x<\pi/2\) 时才拆…
- 上下限代入时下限也必须代入；\((- \cos t)|_0^x=-\cos x+1\)，不能漏掉 \(\cos0=1\)。
- 中间段表达式是 \(1+x-2\sin x\)，不要抄成 \(1+x+2\sin x\)。
- 分段点 \(x=0,\pi/2\) 处求导数要用导数定义或左右导数，不能只套分段内导数。
- 在 \([0,\pi/2]\) 上 \(\cos x\) 单调递减，\(\cos\frac{\pi}{6}>\cos\frac{\pi}{4}>\cos\fr…

| 字段 | 值 |

| action_gap_type | B4-CHAIN |
| expected_first_action | 先画 \(t\) 轴，标出固定积分区间 \([0,\pi/2]\) 和绝对值分段点 \(t=x\)，判断 \(t=x\) 是否落在积分区间内。 |
| missed_action | 知道要处理绝对值，但没有把分段点归到积分变量 \(t\) 轴上；误围绕 \(x\) 与 \(t\) 混合讨论范围，后续还漏代下限 \(\cos0\)、抄错中间段符号，并未用导数定义检查分段点。 |
| related_method_card_id | H09-007 |
