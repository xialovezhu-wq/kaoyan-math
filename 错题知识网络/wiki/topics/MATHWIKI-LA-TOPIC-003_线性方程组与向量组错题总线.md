# 线性方程组与向量组错题总线

线性方程组和向量组题的共同核心是秩、自由变量、解空间和线性相关关系。不要把“行变换算完”当成最终目标。

## 索引型簇

- [[MATHWIKI-KNOWLEDGE-030_线性方程组]]
- [[MATHWIKI-KNOWLEDGE-066_向量组线性相关]]
- [[MATHWIKI-KNOWLEDGE-062_矩阵秩]]

## 第一动作

| 题面信号 | 先做动作 | 常见断点 |
|---|---|---|
| 齐次方程组 | 先判断秩和自由变量个数 | 算出一组解后忘记解空间维数 |
| 非齐次方程组 | 先比较系数矩阵秩和增广矩阵秩 | 忽略相容条件 |
| 线性相关/无关 | 先把问题转成系数方程或秩判断 | 只凭向量个数下结论 |
| 矩阵等式给出一组特征向量候选 | 先按列读，再用秩判断能提供几个独立方向 | 把列数或行数直接当作特征空间维数 |
| 极大无关组/基础解系 | 先确认对象空间和列/行关系 | 行向量、列向量对象混淆 |
| 矩阵方程 \(AP=B\) | 按列拆成 \(Ap_i=b_i\) | 只把 \(P\) 当整体硬算，漏掉每一列都是非齐次方程组 |
| 矩阵方程 \(AB=A\) 且 \(A\) 不可逆 | 写 \(A(B-E)=O\)，列向量进入 \(\mathcal N(A)\) | 错误消去奇异矩阵 \(A\) |
| \(A^2x=0\) 与 \(Ax=0\) 解不同 | 先判 \(A\) 可逆时二者都只有零解，因此推出 \(|A|=0\) | 直接硬算 \(A^2\)，没有用核空间关系降维 |
| 向量组“能表示/不能表示” | 先翻译成 \(\operatorname{span}\) 包含关系 | 只算一个行列式，没回代检查双向条件 |
| 两个含参向量组等价 | 先写两个向量组生成空间相同，再转成秩相等与退化点回代 | 只排除行列式为零的点，漏掉退化但仍等价的参数 |
| 非齐次方程组解集包含 | 拼接 \((A,\alpha)\)、\((B,\beta)\)，比较上下拼接增广矩阵与 \((A,\alpha)\) 的秩 | 分别求通解，漏掉秩关系可直接证明包含 |
| 同一向量可由两组向量表示 | 写 \(k_1\alpha_1+k_2\alpha_2=k_3\beta_1+k_4\beta_2\) | 逐个试选项，没先求两个张成空间的交 |
| 三向量相关且任意两个无关 | 先用 \(r(\alpha_1,\alpha_2,\alpha_3)<3\) 找候选，再逐对回代 | 只满足整体相关，漏查两两无关 |
| 向量组可表示并问转置方程 | 先写 \(A=BC\)，转置后判断核空间包含方向 | 把可表示误当成同解、可逆或双向等价 |
| \(A^{k-1}a\ne0,A^ka=0\) 证明向量组无关 | 设线性组合为零，再左乘 \(A\) 的幂逐个杀系数 | 没把“无关”落成系数方程，或者只证核空间一个包含方向 |
