# 定积分错题总线

定积分错题的核心是变量、区间、结构中心和边界。先看积分对象，再选换元、分部、对称、分段、变上限或反常判敛。

## 第一动作

| 题面信号 | 先做动作 | 常见断点 |
|---|---|---|
| 根式二次式、平方差 | 先找结构中心，再决定平移、配方或三角换元 | 只换上下限不处理 dx |
| 对称区间、平移区间 | 先设整体被积函数，再检验整体奇偶性 | 只看单项不看整体 |
| \(f(x+T)-f(x)\) 平移差分关系 + 已知某段积分 | 先把目标区间拆补成两个相差 \(T\) 的同长区间积分之差，再平移换元 | 硬求 \(f(x)\)；没有把已知积分为零用于区间拆补 |
| 绝对值三角函数 + 任意起点区间 | 先化简绝对值或根式，再看周期和区间长度；必要时拆成整周期与余段 | 把题面参数当作依赖结论，没检查整周期；把半周期余段误当成整周期 |
| 绝对值、分段函数、变上限 | 先画轴排序：下限、分段点、上限变量 | 默认变量为正或漏讨论区间 |
| 多个候选区间比较 \(\int_a^b f(x)\,dx\) 最大/最小 | 先找零点与正负区间，把积分看成带符号面积 | 机械计算全部选项；没区分负面积和正面积的净贡献 |
| 含参绝对值定积分 | 先区分外部参数和积分变量，把分段点放到积分变量轴 | 把 \(x\) 与 \(t\) 的范围混在一起 |
| 含参变限积分 \(f(g(x,t))\) | 先把积分变量和外部参数分开，对积分变量换元时把外部参数当常数 | 想到换元但停在参数反解，未写 \(dt\)；特殊点套非零点公式 |
| \(\int_0^1 f(xt)\,dt\) 型含参积分函数 | 先令 \(u=xt\)，把 \(x\ne0\) 时的函数改写为 \(\frac1x\int_0^x f(u)\,du\)，再单独处理 \(x=0\) | 把 $t$ 与 $x$ 混成同一变量；在 $x=0$ 直接套 $x\ne0$ 的公式；只求出 \(g'\) 没证明连续 |
| 二阶导定号 + 积分不等式 + 区间中点函数值 | 先在区间中点做泰勒展开，得到点态不等式后再对整个区间积分 | 展开后停在点态不等式，没有用定积分保序和中点线性项积分为 0 收口 |
| 单调函数 + 积分不等式 + 固定上限 \(b\) | 先移项，把 \(b\) 变量化为 \(t\) 构造变上限辅助函数 \(F(t)\)，再用 \(F(a)=0\) 和 \(F'(t)\ge0\) 收口 | 只盯原式不变量化；变上限求导混淆哑变量和上限变量；漏负号；没有把 \((t-a)f(t)\) 写成 \(\int_a^t f(t)\,dx\) 做同区间比较 |
| 平板质心横坐标 + 曲线下方面积 | 先写 \(\bar x=\frac{\int_D x\,dA}{\int_D dA}\)，曲线下方区域化为 \(\frac{\int_0^a x f(x)\,dx}{\int_0^a f(x)\,dx}\) | 把质心当作图形上的点；忘记分子是面积矩；比值不等式没有先交叉相乘 |
| 反函数 + 积分范围 + 凹凸性或端点值 | 先画 \(y=f(x)\)、\(y=f^{-1}(x)\) 和端点弦线，把凹凸性转成反函数图像的面积上下界 | 急着求反函数；把 \(\int f^{-1}\) 当成原函数面积；没有用端点弦线放缩 |
| 曲线 + 水平线 + 竖直边界围成面积 | 先设交点横坐标 \(\alpha\)，圈出真实封闭区域；交点同时满足两条曲线方程，例如 \(k=\sin\alpha\)，面积积分里扫描变量另取 \(t\) | 把矩形误当指定曲边区域；把水平线高度 \(k\)、交点横坐标和积分变量混在一起 |
| 参数方程闭合曲线 + 面积/弧长/旋转体综合 | 先解 \(x(t)=0,y(t)=0\) 切参数段，再验镜像对称；面积、弧长、体积、表面积分别选择公式和有效积分限 | 把 \(t\) 当横坐标；只会写 \(0\le t\le2\pi\)，不会判断何时乘 4、何时取上半边母线 |
| 旋转体体积 + 参数区间 | 先把体积写成关于参数的函数 \(V(t)\)，再对变限积分求导 | 直接急着算定积分，忘记目标是求使体积最大的参数 |
| 反常积分 | 先找反常点，再看主项阶数 | 把必要条件当充分条件 |
| 反常尾积分与对数构成无穷比无穷型 | 先在固定常数点拆开尾积分，确认变下限导数，再把 $\ln(1/x)$ 化成 $-\ln x$ | 误以为固定的 $+\infty$ 阻止求导；混淆 $\ln(1/x)$ 与 $1/\ln x$ |
| 有理函数反常积分 | 先因式分解并做部分分式，再把无穷上限写成极限 | 把无穷上限当普通端点，或对数差没有合成商就取极限 |
| 反常积分已求出原函数，且原函数含单独发散项 | 先设共同有限上限 $b$，写完整 $F(b)-F(a)$；将对数差或其他抵消项合并后再令 $b\to+\infty$ | 在某个单独发散项处提前停止；把两个发散极限拆开后相减；换元系数或端点特殊值未复查 |

## 复盘提醒

定积分题不要从公式库开始，要从“区间、变量、结构中心、边界点”开始。含绝对值三角函数时额外先问：被积函数的真实周期是多少，区间长度是否是整周期，是否还有余段。含参变限积分额外先问：积分变量是谁、外部参数是谁、特殊点能不能套非零点公式。

若题目给 \(f''\) 定号并要求证明 \(\int\) 型不等式，右端又是区间长度乘中点函数值，先在中点泰勒展开得到点态比较，再把比较式放到整个区间上积分；中点展开的一次项常因对称积分为 0。

若题目给单调性并要求证明 \(\int_a^b x f(x)\,dx\) 与 \(\int_a^b f(x)\,dx\) 的不等式，优先移项并把固定上限变量化为 \(t\)。构造 \(F(t)\) 后，求导时保留 \(-\frac12\int_a^t f(x)\,dx\) 的负号；收口时把 \((t-a)f(t)\) 改写为 \(\int_a^t f(t)\,dx\)，再用单调性比较同区间内的 integrand。

若题目给曲线、水平线和竖直边界围成 \(S_1,S_2\)，不要把图中看起来像矩形的部分直接当作面积。先设交点参数 \(\alpha\)，由交点条件写出 \(k=f(\alpha)\)，再按上下函数相减写积分；积分变量只负责扫描区域，建议另取 \(t\) 或 \(u\)。

若题目给参数方程闭合曲线并同时求面积、弧长、旋转体体积或表面积，先解 \(x(t)=0,y(t)=0\) 找轴交点并切参数段，再验证镜像对称。面积先按 \(S=\int y\,dx\) 的几何方向换元，弧长按非负长度积分；绕 \(x\) 轴表面积只取生成母线，上下半边若生成同一外表面不能重复计算。
