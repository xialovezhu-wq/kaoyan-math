# 一元函数微分学应用错题总线

这一类错题的复盘重点是把题目语言翻译成函数形态和导数信息。不要先追公式，先问“题目给了哪种局部结构”。

## 第一动作

| 题面信号 | 先做动作 | 常见断点 |
|---|---|---|
| 可导、导数定义、增量 | 先写差商入口，统一增量变量 | 没有把条件转成差商或一阶线性主部 |
| 分段函数求导和极值 | 先分段求导，再单独列分段点、不可导点和各段驻点 | 只解各段 \(f'=0\)，漏掉拼接点也是极值候选 |
| \((x-a)^2\mid[f(x)-c]\) 或平方因式整除 | 先写 \(f(x)-c=(x-a)^2Q(x)\)，立刻推出 \(f(a)=c,\ f'(a)=0\) | 只代根、漏导数条件，或把 \(Q(x)\) 误设为常数 |
| 多因子乘积在特殊点求导 | 先代点找零因子；若只有一个零因子，只保留“导零因子 × 其他非零因子” | 误判零因子数量，或漏掉零因子的导数系数 |
| \(\frac{f(x)}{x^\alpha}\) 型极限条件判断可导 | 先写 \(f'(0)=\lim_{x\to0}\frac{f(x)-f(0)}x\)，再查 \(f(0)\) 和阶数 | 把 \(0\cdot\infty\) 当成 \(0\)，或把可导误当成 \(f(0)=0\) |
| 变上限积分函数求闭区间最值 | 先求导，再判导数分母符号、找驻点，最后列端点值和驻点值比较 | 求导后直接看区间、误判二次分母、只找局部极值不比较全局最值 |
| 单调、极值、零点个数 | 先判断要研究原函数、导函数还是辅助函数 | 变量层级错位 |
| 中值定理证明 | 先找闭区间、端点关系、要构造的辅助函数 | 直接套定理名，没构造对象 |
| 凹凸、拐点、切线 | 先明确一阶、二阶、三阶导数分别承担什么判断 | 把局部形态判断当成代数计算 |
| 给出 \(f'(x)\) 图像判断 \(f(x)\) 极值/拐点 | 极值点看 \(f'\) 正负变号；拐点看 \(f'\) 单调性改变 | 把 \(f'=0\) 或 \(f'\) 图像特殊点直接当成 \(f\) 的拐点 |
| 高阶导数在 \(0,\pi,2\pi\) 等周期点取值 | 先判原函数整体奇偶性与周期性，再递推导函数奇偶性 | 看到三阶导就硬求，没先用周期性把点拉回 \(0\) |
| 曲率圆、曲率半径、参数曲线曲率 | 先判变量对象：\(y=f(x)\)、\(R(x),s(x)\)，还是 \(x(t),y(t)\) | 公式会背，但没有先确认导数到底是对 \(x\)、\(s\) 还是 \(t\) |
| 二阶小量极限 + 曲率相等 + 充分必要判断 | 先令 \(F=f-g\) 做二阶 Taylor，再分 \(A\Rightarrow B\)、\(B\Rightarrow A\) 两向验证 | 只证明充分性就当成充分必要；忘记曲率公式含 \(|y''|\) |
| 参数方程曲线求曲率 | 先选路线：参数曲率公式，或普通函数曲率公式；若走普通公式，先求 \(y'=\frac{dy/dt}{dx/dt}\)，再用 \(\frac{d}{dx}=\frac{d}{dt}\cdot\frac{dt}{dx}\) 求 \(y''\) | 只对 \(t\) 求导，漏掉 \(\frac{dt}{dx}=\frac1{dx/dt}\) |
| 渐近线、全部渐近线 | 先列定义域端点、\(x\to+\infty\)、\(x\to-\infty\)；参数方程先找无穷远对应参数趋向 | 只算正无穷、只算 \(k\)、或把参数 \(t\) 当成普通 \(x\) 直接套 |
| 隐函数曲线在指定 \(x\) 处求法线斜率 | 先代 \(x=x_0\) 解出对应点，再隐函数求 \(y'\)，最后取负倒数 | 没有先定点；把切线斜率直接当法线斜率 |
| 法线在坐标轴上的截距或截距最值 | 先写点处法线方程，再令对应坐标为 \(0\)，把截距化成单变量函数 | 直接盯截距，没先确定函数、切线斜率和法线斜率 |
| 隐函数求二阶导 | 先判断是否可用对数、恒等变形等把原方程化简；再明确 \(y=y(x)\) 连续求导 | 主线会做，但商法则后减括号变号、复合分式通分和外层分母处理不稳 |
| 相关变化率、水平速度、距离变化率 | 先写静态几何关系和曲线关系，再统一对时间 \(t\) 求导 | 只“知道公式”，但没有把公式改写成可求导的约束等式 |
| 质心横坐标位置不等式 | 先把 \(\bar x\) 翻译成 \(\frac{\int_D x\,dA}{\int_D dA}\)，再交叉相乘构造辅助函数 | 凭图像猜位置，或只写出质心公式但没有把比值不等式转成导数判号 |
| 反函数积分面积比较 + 凹凸性 | 先用端点值画弦线，再把凹凸性翻译成函数图像与弦线的位置关系 | 把 \(\int f^{-1}\) 误当成原函数面积，或只想套中值定理 |
| 复合增量、反向输入、去心补点求导 | 先找基点、真实增量和补点位置，再决定用差商、求导关系还是 Taylor | 把外层变量当成真实增量，或把 \(x\ne0\) 公式硬代到补点 |
| 绝对值、单侧复合、导函数极限命题 | 先列候选点并标明判断对象：点处导数、去心导函数极限、局部符号还是参数曲线 | 看到绝对值就判不可导，或把右侧信息误当双侧信息 |

## 新增训练项：相关变化率静态关系入口
