# 线代矩阵运算错题总线

本页先把线代高频错题从全量错题卡里挂入 wiki。当前是第一版总线，后续再按相似、秩、方程组、特征值、二次型拆专题。

## 第一动作

| 题面信号 | 先做动作 | 常见断点 |
|---|---|---|
| 矩阵乘法、逆、转置 | 先检查维数、顺序、可逆条件 | 把数乘直觉套到矩阵乘法 |
| 秩、线性相关 | 先把对象转成行列变换或方程组 | 只看形式不看自由变量 |
| 特征值、特征向量 | 先写特征方程和特征子空间 | 把特征值代入后漏解向量空间 |
| 可交换矩阵与可对角化 | 先拆充分/必要两个方向；充分性看特征子空间是否被保持 | 把单向充分条件误当成充要条件 |
| 相似对角化中更换特征向量矩阵 | 逐列判断新矩阵每一列对应哪个特征值 | 把同一特征空间内换基误判成对角元重排 |
| 判断能否相似于对角矩阵 | 先找重特征值，再算几何重数 | 上三角矩阵只看对角线，不查重根特征空间维数 |
| 实对称矩阵与正交特征向量组互判 | 先把正交特征向量单位化组成正交矩阵 \(Q\) | 只记住实对称充分性，漏掉反向推导 |
| 实对称矩阵每行元素之和相等 | 先写 \(A\mathbf 1=c\mathbf 1\)，再用正交补处理剩余特征空间 | 设未知矩阵硬解，漏掉行和给特征向量 |
| \(A\sim B\) 后判断转置、逆、伴随、矩阵函数组合 | 设 \(B=P^{-1}AP\)，逐项检查是否能落到同一个 \(P^{-1}(\cdot)P\) | 把分别相似的两项直接相加 |
| \(A^*\sim B\)，求参数、\(Q\) 和高次幂 | 先比较特征值求参数，再构造特征向量矩阵 | 只求出参数，不处理换基矩阵和 \(A,A^*\) 关系 |
| 正交矩阵某元素等于 \(1\) | 用行列向量单位长度锁定同一行/列其余元素为 \(0\) | 只套 \(A^{-1}=A^{\mathsf T}\)，漏掉首元强约束 |
| 多元线性递推求通项 | 写 \(\alpha_n=A\alpha_{n-1}\)，再求 \(A^n\alpha_0\) | 分量级硬猜，或者写出矩阵后没有对角化求幂 |
| 上三角矩阵对角线全为 \(1\) 且求高次幂 | 写 \(A=E+N\)，先找 \(N\) 的幂零阶数 | 硬乘高次幂，或漏掉二项式中的 \(N^2\) 项 |
| 初等矩阵幂在矩阵左右两边 | 左乘翻译成行变换，右乘翻译成列变换 | 把右乘也当成行变换，或忽略负幂/周期结构 |
| 实对称矩阵满足矩阵多项式方程 | 正交对角化，转为特征值方程 | 把矩阵方程当普通代数式乱约，忘记特征值为实数 |
| \(AB=\lambda B\) 或 \(CA^{\mathsf T}=\lambda C\) | 按列读特征向量；含 \(A^{\mathsf T}\) 时先转置 | 把矩阵等式整体硬解，或误读行列方向 |
| 元素满足 \(a_{ij}=-A_{ij}\)，其中 \(A_{ij}\) 是代数余子式 | 先翻译成 \(A^{\mathsf T}=-A^*\) | 把伴随矩阵和代数余子式矩阵的位置看反，或只得到候选值不排除 \(|A|=0\) |
| 反对称矩阵且目标含 \(A^*\) 或 \(x^{\mathsf T}A^*x\) | 先写 \(A^{\mathsf T}=-A\)，再把反对称性质传给 \(A^*\) | 忘记奇数阶反对称矩阵行列式为 \(0\)，或没有利用二次型恒为 \(0\) |
| 对角线为 \(0\)、非对角线为 \(1\)，要求逆矩阵 | 写 \(A=J-E\)，用 \(J^2=nJ\) 构造逆 | 把全一矩阵结构看丢，转去硬算伴随矩阵 |
| 已知矩阵多项式方程，要求 \((A-cE)^{-1}\) | 用 \(A-cE\) 去除题设多项式 | 余式符号算错，或没有整理成右端为 \(E\) |
| \(A^k=O\)，判断 \(E\pm A\) 可逆 | 识别幂零矩阵，写有限级数逆矩阵 | 把 \(A\) 不可逆误传给 \(E\pm A\) |
| 交换 \(A\) 的两列，问 \(B^*\) 与 \(A^*\) 的关系 | 写 \(B=AE_{ij}\)，再用 \((AB)^*=B^*A^*\) | 忘记伴随矩阵乘积反序，或把列交换误判成 \(A^*\) 的列交换 |
| 已知 \(P^{-1}AP=B\) 且 \(B\) 为对角矩阵，求 \(A^n\) | 写 \(A^n=PB^nP^{-1}\) | 把 \(A^n\) 直接当成 \(B^n\)，丢掉换基矩阵 |
| 已知 \(A=BC\) 且 \(B,C\) 维数低 | 写 \(A^k=B(CB)^{k-1}C\) | 继续硬算高阶矩阵幂，没有组合中间小矩阵 \(CB\) |
| 横拼矩阵出现 \([A,AB]\) | 按列空间判断 \(AB\) 的列是否在 \(\operatorname{Col}(A)\) 中 | 把 \(AB\)、\(BA\)、转置块和普通横拼的秩性质混为一谈 |
| 分块矩阵秩选项中右上角块为 \(BA\) | 重新检查是否能合法消块，不能照搬 \([A,AB]\) | 把 \(AB\) 与 \(BA\) 当成可交换结构 |
| 已知 \(AB\)，要求 \(BA\)，且 \(A,B\) 不是同阶方阵 | 先算 \(r(AB)\) 与 \((AB)^2\)，再看能否写成 \(A(BA)B\) | 未证满秩就直接消去非方阵乘积 |
| \(ABC=O\)，比较多个分块矩阵的秩 | 逐个分块消元，化出每个秩的表达式 | 把 \(ABC=O\) 当作直接排序结论 |
| \(A(A-A^*)=O\) | 先写秩不等式和 \(AA^*=|A|E\) | 只把伴随矩阵条件当普通乘积为零 |
| 分块上三角矩阵求 \(M^*\) | 设 \(M^*=\begin{pmatrix}X&Y\\Z&W\end{pmatrix}\)，用 \(MM^*=|M|E\) | 机械拼接 \(A^*,B^*\)，漏掉负号和行列式因子 |
| \(P=[\alpha,A\alpha]\)，且 \(AP=PB\) | 把 \(AP\) 拆成 \([A\alpha,A^2\alpha]\)，逐列写新基坐标 | 没有意识到 \(B\) 的列是坐标列 |
| \(P^{-1}AP=J\) | 改写为 \(AP=PJ\)，按列构造 Jordan 链 | 随便选 \(P\) 的列，没有按目标 Jordan 块递推 |
| \(AP=B\) 且要求 \(P\) 可逆 | 先令 \(P=(p_i)\)，拆成 \(Ap_i=b_i\)，最后查 \(|P|\ne0\) | 只解出通解，忘记可逆性条件 |
| \(AB=A\) 且 \(A\) 不可逆 | 写 \(A(B-E)=O\)，把 \(B-E\) 的列放进 \(\mathcal N(A)\) | 错误左消 \(A\) |
| \(A^{k-1}a\ne0,\ A^ka=0\) | 设线性组合为零，再左乘 \(A\) 的幂逐个杀系数 | 只凭幂零直觉说线性无关，没有证明系数全为零 |
| 证明 \(r(A^{n+1})=r(A^n)\) | 先比较 \(\mathcal N(A^n)\) 与 \(\mathcal N(A^{n+1})\) | 只证一边包含，没用反证补反向包含 |

线代题先判对象和维数，再做等价变换。每一步都要保持对象类型一致。逆矩阵题额外先问：能否通过全一矩阵、矩阵多项式、幂零矩阵或秩一扰动直接构造逆矩阵。伴随矩阵题额外先问：题面给的是代数余子式矩阵，还是伴随矩阵 \(A^*\)，是否需要先转置；若题面做了行列初等变换，还要检查传到伴随矩阵后乘积顺序是否反过来。高次幂和秩题先看能否降维：相似对角化、低秩分解和列空间包含通常比硬算更稳。矩阵方程题优先按列拆：\(AP=B\) 拆成 \(Ap_i=b_i\)，\(AB=A\) 转成 \(A(B-E)=O\)，相似到 Jordan 块转成 \(AP=PJ\)。
