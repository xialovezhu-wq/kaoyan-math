# 多元函数极值驻点判别

本页用于收口多元函数无条件极值题的第一动作。核心不是先猜图像，而是先判断题型：标准无条件极值走驻点和 Hessian 判别；若题目在比较路径或判别式失效，则回到极值定义。

## 第一动作

看到“求二元函数极值 / 判断某点是否为极值点”，先问：

1. 是否是标准无条件极值题。
2. 是否已经给出可疑点，需要验证它是不是极值点。
3. 是否只给了沿直线、沿路径或某个限制函数的信息。

标准流程：

$$
\begin{aligned}
&\text{第一步：联立 } f_x=0,\ f_y=0 \text{ 求全驻点};\\
&\text{第二步：在每个驻点计算 } A=f_{xx},\ B=f_{xy},\ C=f_{yy};\\
&\text{第三步：用 } D=AC-B^2 \text{ 判别};\\
&\text{第四步：若 } D=0 \text{ 或题目只给路径信息，回到定义/路径符号。}
\end{aligned}
$$

## 判别规则

| 条件 | 结论 | 下一步 |
|---|---|---|
| \(D>0,\ A>0\) | 极小值点 | 代回函数值 |
| \(D>0,\ A<0\) | 极大值点 | 代回函数值 |
| \(D<0\) | 非极值点 | 说明为鞍点或非极值 |
| \(D=0\) | 二阶判别法失效 | 用定义、路径或区域符号判断 |
| 只知道所有直线限制上极小 | 不能推出二维极小 | 找曲线路径或分区符号验证 |

## 易错边界

- “沿任意直线 \(y=kx\)”成立，只说明所有直线路径上的限制函数表现，不等于二维邻域内函数都不小于 \(f(P)\)。
- \(D=0\) 不是“有极值”，也不是“无极值”，只是二阶充分条件失效。
- 驻点求完后必须逐点判别；不能只算一个候选点。
- 判出极值点后还要代回函数求极值，不要停在点坐标。

| [GS-388](http://127.0.0.1:8765/open/GS-388) | \((y-x^2)(y-x^3)\) 极值 | 先求全驻点，再分别判别 | \(D=0\) 时改用路径/定义法 |
| [GS-389](http://127.0.0.1:8765/open/GS-389) | \(x^3+8y^3-xy\) 极值 | 联立一阶偏导为零 | 驻点、判别、代值三步都要闭环 |
| [GS-390](http://127.0.0.1:8765/open/GS-390) | \(3(x^2+y^2)-x^3\) 无条件极值 | 联立一阶偏导求 \((0,0),(2,0)\) | \(D<0\) 的驻点是鞍点，不是极值点 |
| [GS-392](http://127.0.0.1:8765/open/GS-392) | \(z=f(x)f(y)\) 在 \((0,0)\) 取极大值 | 先求二元二阶偏导，再看 \(f(0)f''(0)\) 符号 | 一元驻点只给候选，极大还要 Hessian 符号 |
