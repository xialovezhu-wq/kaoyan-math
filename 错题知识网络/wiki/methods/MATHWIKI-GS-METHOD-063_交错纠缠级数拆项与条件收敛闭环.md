# 交错纠缠级数拆项与条件收敛闭环

本页沉淀第 16 讲无穷级数中一类高频入口：通项里有 \((-1)^n\)，但它和对数、根式、三角相位、有理因子或证明目标纠缠在一起。第一动作不是直接套莱布尼茨，而是先把通项拆成可判别的标准块。

## 第一动作清单

| 题面信号 | 先做动作 | 对应错题 |
|---|---|---|
| \(\ln(1+\frac{(-1)^n}{n^p})\) | 令 \(x_n=\frac{(-1)^n}{n^p}\)，展开到二阶 | [[GS-597_138757对数交错级数分类]] |
| \(\frac{(-1)^n}{\sqrt{n+(-1)^n}}\) | 提出主量 \(\sqrt n\)，写成 \(\frac{(-1)^n}{\sqrt n}(1+\frac{(-1)^n}{n})^{-1/2}\) | [[GS-598_138763根式扰动交错级数]] |
| \(\sin(\pi\sqrt{n^2+1})\) | 拆相位 \(n\pi+\pi(\sqrt{n^2+1}-n)\)，制造 \((-1)^n\) | [[GS-599_138778隐藏交错正弦级数]] |
| 分子两项相加且每项可与分母约分 | 先按分子拆成两个标准级数 | [[GS-606_138781加法项拆等比调和判散]] |
| 有理因子分子分母只差常数 | 凑成 \(1-\frac{c}{\text{分母}}\)，拆主项和余项 | [[GS-607_138782交错有理因子拆主余项]] |
| 已知 \(\sum |a_n|\) 收敛，证明 \(\sum a_n\) 收敛 | 构造 \(0\le a_n+|a_n|\le2|a_n|\) | [[GS-608_138784绝对收敛推收敛构造非负项]] |
| 已知交错级数条件收敛，目标含 \(u_{2n},u_{2n-1}\) | 先把条件收敛翻译成原交错级数收敛、正项级数发散，再做奇偶项拆分 | [[GS-502_102347条件收敛奇偶拆分]] |

## 收敛类型闭环

判断“绝对收敛 / 条件收敛 / 发散”时，不要只判原级数：

1. 先判原级数是否收敛。
2. 再判绝对值级数是否收敛。
3. 原级数收敛且绝对值级数收敛，结论是绝对收敛。
4. 原级数收敛但绝对值级数发散，结论是条件收敛。
5. 原级数发散时，不再说条件收敛。

拆项后要分别给每一块的性质，再合成：

- 收敛级数加发散级数必发散。
- 条件收敛级数加绝对收敛级数仍是条件收敛。
- 发散级数加发散级数不一定发散，不能乱用线性性质。

## 常见断点

- B2-TRIGGER：看到 \((-1)^n\) 就急着套莱布尼茨，没有先拆外层函数或有理因子。
- B4-CHAIN：通项趋零后动作中断，把必要条件误当成收敛结论。
- B5-CHECK：原级数已判收敛，但忘记补查绝对值级数。
- B7-CALC：根式有理化、负底数幂符号、二项式展开系数或 \(p\) 级数指数判断出错。

## 复做提醒

看到交错纠缠项，先问三句话：

1. 外层函数能不能泰勒展开？
2. 相位或有理因子能不能拆出标准交错主项？
3. 判完原级数后，绝对值级数查了吗？

若题目是证明“绝对收敛推出收敛”，第一动作固定为
\[
0\le a_n+|a_n|\le2|a_n|,
\qquad
a_n=(a_n+|a_n|)-|a_n|.
\]
