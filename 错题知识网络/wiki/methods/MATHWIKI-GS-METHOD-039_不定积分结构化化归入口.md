# 不定积分结构化化归入口

## 定位

本页收口第 9 讲不定积分中常见的“先化归，再套基本公式”入口。它不保存完整题解，只记录复做时应先触发的结构判断。

## 核心结论

- 乘积型积分先问：是否有一个因子求导后明显变简单，另一个因子容易积分。若是，优先考虑分部积分。
- 有理函数积分先问：分母是否已经能分解成线性因子、重复线性因子、不可约二次因式。模板必须一次写全。
- 三角幂函数先问：\(\sin x\) 或 \(\cos x\) 是否有奇次幂。奇次幂通常拆出一个微分因子，再把剩余偶次幂用恒等式改写。
- 三角有理式先问：能否补分子、半角/倍角化、把分母当整体、查参数退化，或拆项后用分部积分抵消；万能代换是兜底，不是固定第一步。详见[[MATHWIKI-GS-METHOD-042_三角函数有理式入口四分流]]。
- 根式积分先问：根式是不是完整复合整体，幂次能否统一，换元后是否需要反解原变量，以及最后如何回代。详见[[MATHWIKI-GS-METHOD-043_根式积分换元与回代链]]。

## 第一动作表

| 题面信号 | 第一动作 | 典型断点 |
|---|---|---|
| 指数因子乘反三角复合函数 | 先把反三角复合函数作为 \(u\) 作分部积分 | 直接换元导致整式无法化简 |
| \((x-a)^k\) 与不可约二次因式同现 | 写全 \(\frac{A_1}{x-a}+\cdots+\frac{A_k}{(x-a)^k}+\frac{Mx+N}{Q_2(x)}\) | 漏重复因式高阶项，或二次因式分子只写常数 |
| \(\sin^m x\cos^n x\) 且某一方为奇次幂 | 拆出一个对应微分因子，再用 \(\sin^2+\cos^2=1\) 统一变量 | 没先决定用 \(d(\sin x)\) 还是 \(d(\cos x)\) |
| 三角有理式 | 先按[[MATHWIKI-GS-METHOD-042_三角函数有理式入口四分流]]判断补分子、半角/倍角、分母整体、参数退化或分部抵消 | 固定套一种模板，或把万能代换当唯一入口 |
| 根式复合整体、根式套分式、分数幂混杂 | 先按[[MATHWIKI-GS-METHOD-043_根式积分换元与回代链]]判断整体换元、幂次统一、三角换元或部分分式路线 | 只换根式不换 \(dx\)，或停在新变量/三角函数没有回代 |
| 分母整体 \(F(x)\) 与分子接近 \(F'(x)\) | 先算 \(F'(x)\)，再把分子写成 \(AF'(x)+BF(x)\) | 不朝分母导数方向整理 |
| 参数型三角分母 | 先查参数能否为 \(0\)，再处理非零主情形 | 把“参数不同时为零”误当作“每个参数都非零” |
| 分部积分或反常积分边界项外有负号 | 每一步先保留括号，再逐项分配符号 | 把 \(-(-a)\) 误写成 \(-a\)，或把细节错泛化成不会积分 |
| 多个指数底数构成分式平方差 | 先同除主因子，令 \(u=a^x\)，再检查 \(du=\ln a\cdot u\,dx\) 是否吸收原式 | 只换 \(a^x\)，漏掉 \(u\,dx\) 和 \(\ln a\) |
| 分母含 \(1-x^4\)、\(1+x^2\) 等可继续拆分结构 | 先拆到基本有理函数块，再分别接对数或反正切公式 | 拆到一半就停，漏掉反正切项 |
| 分母平方 \((x+a)^2\) 且分子导数可降幂 | 写 \(dx/(x+a)^2=-d(1/(x+a))\)，用分部积分降幂 | 只看见分母平方，没把它当作可凑微分对象 |

## 复做链条

1. 先判结构：乘积、分式、三角幂、有理三角式。
2. 再选化归动作：分部、部分分式、凑微分或万能代换。
3. 化归后必须检查新积分是否已经落到基本公式。
4. 回代时统一变量，检查常数因子、符号和绝对值。
