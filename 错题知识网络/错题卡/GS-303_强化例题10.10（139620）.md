# 强化例题10.10（139620）：三角变上限曲线全长

## 题目摘要

求曲线

\[
y=\int_0^x\sqrt{\cos t}\,dt
\]

的全长。

## 正确第一步

先确定定义域并求导：

\[
\cos x\ge0,\qquad -\frac\pi2\le x\le \frac\pi2,
\]

\[
y'(x)=\sqrt{\cos x}.
\]

## 标准答案与关键过程

弧长

\[
s=\int_{-\pi/2}^{\pi/2}\sqrt{1+\cos x}\,dx.
\]

由

\[
1+\cos x=2\cos^2\frac x2,
\]

且在 \([-\frac\pi2,\frac\pi2]\) 上 \(\cos\frac x2\ge0\)，得

\[
s=\int_{-\pi/2}^{\pi/2}\sqrt2\cos\frac x2\,dx=4.
\]

## 具体错点

本轮已经正确得到 \(\sqrt{\cos t}\) 的完整实值区间，却因为积分写成从 0 到 x，误以为 x 不能取负值，于是删去 \([-\frac\pi2,0]\)，只计算了右半段。

这里必须区分：0 是固定积分起点，不是自变量 x 的最小允许值。当 \(x<0\) 时，

\[
\int_0^x f(t)\,dt=-\int_x^0 f(t)\,dt.
\]

因此负半区间仍然对应曲线的一部分。

## 本轮独立正确步骤

- 独立由 \(\sqrt{\cos t}\) 判断包含 0 的最大连续实值区间。
- 独立得到 \(y'(x)=\sqrt{\cos x}\)，并正确选用直角坐标弧长公式。
- 正确使用半角公式，算出右半段弧长为 2。

## 方法断点

本轮不是没有检查根号定义域，而是混淆了“定积分的固定起点”和“函数自变量的定义域”。正确动作链是：先独立确定 x 的完整实值区间，再理解 x 小于 0 时定积分方向反转，最后在整个区间上计算全长。

助手关于反向定积分与偶性的说明只记为提示，不作为用户独立掌握证据。

- 入口识别：变上限积分定义曲线，先求 \(y'\)；“全长”还要先确定实值定义域。

## 易错陷阱

- \(\int_0^x\) 的固定起点为 0，不代表 \(x\ge0\)
- \(\sqrt{\cos t}\) 要求 \(\cos t\ge0\)，全长区间为 \([-\frac\pi2,\frac\pi2]\)
- 弧长被积函数是 \(\sqrt{1+\cos x}\)，不是 \(\sqrt{\cos x}\)
- \(\sqrt{1+\cos x}\) 要用半角公式，并注意 \(\cos\frac x2\ge0\)

## 复做提醒

- 看到从 0 到 x 的变上限积分，先把“固定起点”和“x 的定义域”分开；允许 x 取负值，再在完整区间上求全长。
