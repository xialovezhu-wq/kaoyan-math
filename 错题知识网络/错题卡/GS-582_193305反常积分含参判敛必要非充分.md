# GS-582 193305 反常积分含参判敛必要非充分

## 题目摘要

已知 \(I=\int_2^{+\infty}\left(e^{\frac{\ln x}{x^a}}-1\right)dx\) 收敛，求 a 的范围（选 C：(1,+∞)）。

## 标准答案

C。
- a≤0：\(\frac{\ln x}{x^a}\) 不趋 0（a=0 得 x-1，a<0 趋 +∞），被积不趋 0，发散。
- a>0：\(\frac{\ln x}{x^a}\to0\)，\(e^u-1\sim u\) ⇒ 原积分与 \(\int_2^{+\infty}\frac{\ln x}{x^a}dx\) 同敛散。
- 该积分 a>1 收敛（取 ε 使 a-ε>1，ln x<xᵋ 放缩），0<a≤1 发散（ln x≥1 比 1/xᵃ；a=1 时 \(\int\frac{\ln x}{x}dx=\frac12(\ln x)^2\to+\infty\)）。

故 a>1，选 C。

## 具体错点

把「被积函数趋于 0」误当「反常积分收敛」——这只是必要非充分条件（反例 1/x→0 但 ∫₁^{+∞}1/x dx 发散）。a=1 时被积趋 0 但 ~(ln x)/x，积分发散；收敛须趋 0 速度比 1/x 更快，即 a>1。

## 方法断点

- `method_trigger`：无穷限反常积分含参判敛，被积函数趋于 0（尤其边界值处）。
- `expected_method`：被积趋 0 只是必要条件 → e^u-1~u 化简 → 与 1/xᵖ 或 (ln x)/xᵃ 比较判速度（无穷端 p>1、含 log 时 a>1）→ 边界单独验。
- `expected_first_action`：用 e^u-1~u 化成 (ln x)/xᵃ，与 p 型积分比较判趋 0 速度。
- `missed_action`：把「被积趋 0」当「收敛」，边界 a=1 没继续判收敛。
- `action_gap_type`：A-CONCEPT（必要非充分条件概念未建立）。
- `related_method_card_id`：H08-005（反常积分判敛·向标准 p 积分靠近），联动 H01-004（等价无穷小 e^u-1~u）。

## 必要提示

被积函数趋于 0 只是反常积分收敛的必要非充分条件（1/x 是经典反例）；要继续看趋 0 速度。

e^u-1~u 仅当 u→0 可用（本题 a>0 才有 (ln x)/xᵃ→0）。含 log 的 ∫(ln x)/xᵃ dx：a>1 收敛、a≤1 发散，边界 a=1 单独验得发散。

## 复做提醒

反常积分判敛：被积趋 0 是必要非充分，还要判速度；e^u-1~u 化简后与 1/xᵖ、(ln x)/xᵃ 比较（无穷端 p>1、含 log 时 a>1），边界值单独验。
