# GS-760 84893 奇点避让与合法换路径

## 题目摘要

L 从 A(-π/2,0) 沿 y=cos x 到 B(π/2,0)，计算 ∫_L((x-y)dx+(x+y)dy)/(x^2+y^2)。

## 标准答案

-π

## 具体错点

选择穿过原点奇点的 x 轴作为补线或替代路径。

后续不同断点：

- 跨越 x=0 使用 ln x。
- 换路后仍使用旧曲线方程。
- 把 A、B 的参数对应关系反置。

## 方法断点

- 题面触发：被积形式在原点外满足路径无关，但分母在原点为零
- 正确第一动作：检查候选路径是否穿过 (0,0)
- 实际漏项：补 x 轴时没有检查它经过奇点
- 方法卡：H18-011

## 本次独立正确步骤

- 识别 P_y=Q_x 在原点外成立。
- 知道需要利用路径结构简化。

## 证据边界

- 掌握度为 2/5；偏导条件有独立识别；合法换路、奇点边界和方向均需多轮讲解，未独立复算。
- 标准答案和正确路线由题图、解析图与对话交叉核验；助手讲解不计作用户独立完成。
- 尚未观察到无提示闭卷完整复现。

## 复做提醒

换路径前先查奇点和连通区域；换路后只使用新路径的参数与方向。
