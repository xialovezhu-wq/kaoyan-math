# GS-519 102397 卷积型幂级数和函数

## 题目摘要

求 $\displaystyle\sum_{n=1}^{\infty}\left(1+\frac12+\cdots+\frac1n\right)x^n$ 的和函数。答案 $\dfrac{-\ln(1-x)}{1-x}$，$-1<x<1$。

## 标准答案

$\dfrac{-\ln(1-x)}{1-x}$，$-1<x<1$。

## 具体错点

没把系数"前 n 项调和和"看成 $\left(\sum\frac{x^n}n\right)\!\left(\sum x^n\right)$ 的卷积系数；且 $\frac1{1-x}$、$-\ln(1-x)$ 两条展开式不熟。

## 标签

- 知识点：无穷级数、幂级数、幂级数和函数、幂级数乘法（柯西乘积）、常用幂级数展开式、几何级数、对数级数展开
- 错因：题型识别失败（没认出卷积系数）、复习记忆不牢（母展开式不熟）
- 方法：先判型、柯西乘积、卷积系数识别、前 n 项和乘 $\frac1{1-x}$、常用展开式、公共收敛区间取交
- 陷阱：前 n 项和系数 ⇔ 乘 $\frac1{1-x}$；两条母展开式必须背熟；求和函数先在公共开区间操作
- 关键词：日期已归档；幂级数和函数；柯西乘积；卷积系数；常用展开式

## 必要提示

1. 系数为"前 n 项和" $\sum_{k=1}^n\frac1k$ ⇒ 它是 $\left(\sum\frac{x^n}n\right)\!\left(\sum x^n\right)$ 的卷积系数；记忆口诀：**前 n 项和 = 原级数乘 $\frac1{1-x}$**。
2. 母公式：$\sum_{n=0}^\infty x^n=\frac1{1-x}\ (|x|<1)$；$\sum_{n=1}^\infty\frac{x^n}n=-\ln(1-x)\ (-1\le x<1)$。
3. 相乘得 $\dfrac{-\ln(1-x)}{1-x}$，取公共开区间 $(-1,1)$。

## 错题复发记录

- 第 1 次：2026-05-30，没把"前 n 项调和和系数"识别成卷积，且常用展开式不熟。

## 复做提醒

求和函数遇到"系数是前 n 项和 / 累加和"，第一反应：它是某级数与 $\sum x^n$ 的**卷积**，等价于把那个级数**乘以 $\frac1{1-x}$**。前提是把 $\frac1{1-x}$、$-\ln(1-x)$、$e^x$、$\sin/\cos$、$(1+x)^\alpha$ 这几条常用展开式背到能反向认。
