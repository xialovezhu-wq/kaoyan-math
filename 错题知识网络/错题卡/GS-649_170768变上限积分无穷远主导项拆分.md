# GS-649 170768 变上限积分无穷远主导项拆分

## 题目摘要

求极限

\[
\lim_{x\to+\infty}
\frac{
\frac1{x^3}\int_1^x\left[(1+t^2)\sin\frac1t-\cos t\right]dt
}{
1-e^{1/x}
}.
\]

## 标准答案

先用

\[
1-e^{1/x}\sim -\frac1x
\quad (x\to+\infty)
\]

把原式化为

\[
\lim_{x\to+\infty}
\frac{
\int_1^x\left[(1+t^2)\sin\frac1t-\cos t\right]dt
}{
-x^2
}.
\]

对上式使用洛必达法则：

\[
\lim_{x\to+\infty}
\frac{(1+x^2)\sin\frac1x-\cos x}{-2x}.
\]

关键是拆分主导项：

\[
(1+x^2)\sin\frac1x-\cos x
=
x^2\sin\frac1x+\sin\frac1x-\cos x.
\]

于是

\[
\frac{(1+x^2)\sin\frac1x-\cos x}{-2x}
=
\frac{x^2\sin\frac1x}{-2x}
+
\frac{\sin\frac1x-\cos x}{-2x}.
\]

其中

\[
\frac{\sin\frac1x-\cos x}{-2x}\to0,
\]

因为分子有界、分母趋于无穷大；而

\[
\frac{x^2\sin\frac1x}{-2x}
=
-\frac12\cdot \frac{\sin(1/x)}{1/x}
\to
-\frac12.
\]

所以答案为

\[
\boxed{-\frac12}.
\]

## 具体错点

本题前半段不是主要问题。真正断点在洛必达之后：

\[
\frac{(1+x^2)\sin\frac1x-\cos x}{-2x}.
\]

这里不能把整个分子混在一起看，而要先拆成：

\[
\frac{x^2\sin\frac1x}{-2x}
+
\frac{\sin\frac1x-\cos x}{-2x}.
\]

第一项是主导项，给出 \(-\frac12\)；第二项是有界扰动项除以无穷大，直接趋于 0。

- 陷阱：洛必达后仍要判主导项, 有界振荡项除以无穷大趋于 0, \(x^2\sin\frac1x\) 才是主导增长项

## 必要提示

无穷远极限中，只要出现

\[
\text{主导增长项}+\text{有界扰动项},
\]

就先拆开。增长项单独算阶数，有界扰动项除以 \(x\) 或 \(x^2\) 这类无穷大量时直接趋于 0。
