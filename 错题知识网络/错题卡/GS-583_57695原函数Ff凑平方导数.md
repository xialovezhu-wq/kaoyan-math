# GS-583 57695 原函数Ff凑平方导数

## 题目摘要

设 F(x) 是 f(x) 的一个原函数，F(π/4)=0，当 π/4<x<π/2 时 F(x)>0，且 \(F(x)f(x)=\dfrac{\ln(\tan x)}{\sin x\cos x}\)，求 f(x)。

## 标准答案

f(x)=1/(sin x·cos x)。

F'=f ⇒ F·f=F·F'=½(F²)'。两边积分：右边 ∫ln(tan x)/(sin x cos x)dx，令 u=tan x（du=sec²x dx，1/(sin x cos x)=sec²x/tan x）得 ∫(ln u/u)du=½(ln u)²。故 ½F²=½(ln tan x)²+C。由 F(π/4)=0、tan(π/4)=1 ⇒ C=0，F²=(ln tan x)²。π/4<x<π/2 时 tan x>1、ln tan x>0 且 F>0 ⇒ F=ln tan x。f=F'=(ln tan x)'=1/(sin x cos x)。

## 具体错点

已知 F'=f，但看到 F·f 没代回成 F·F'，再凑成 ½(F²)'；把 F、f 当成两个孤立函数。第一动作应是识别「函数乘自己的导数」凑平方，两边积分求 F²，再定常数与符号。

## 方法断点

- `method_trigger`：F 是 f 的原函数 + 出现 F(x)f(x)。
- `expected_method`：F·f=F·F'=½(F²)' → 两边积分求 F² → 初值定 C → F>0 定符号 → f=F'。
- `expected_first_action`：把 F·f 改写成 F·F'=½[F²]'（不是先算右边/硬求 f）。
- `missed_action`：没把 F·f 识别为「函数乘自己的导数」、没凑 ½(F²)'。
- `action_gap_type`：B3-METHOD（方法调取失败：没调出「F·F'=½(F²)' 凑平方」）。

## 必要提示

看到 F 是 f 的原函数、又出现 F·f：F·f=F·F'=½(F²)'，这是凑平方导数的标准入口。

两边积分得 ½F²，右边凑微分 u=tan x 化成 ∫ln u/u du=½(ln u)²；再用 F(π/4)=0 定 C=0、用 F>0 定正号开方。
