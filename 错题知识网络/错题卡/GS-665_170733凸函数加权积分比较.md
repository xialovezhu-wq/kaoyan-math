# GS-665 170733 凸函数加权积分比较

## 题目摘要

设 \(f(x)\) 在 \([0,a]\) 上有二阶连续导数，且

\[
f(0)=0,\qquad f''(x)>0.
\]

比较

\[
3\int_0^a x f(x)\,dx
\]

与

\[
2\int_0^a a f(x)\,dx=2a\int_0^a f(x)\,dx
\]

的大小关系。

## 标准答案

\[
\boxed{B}
\]

即

\[
3\int_0^a x f(x)\,dx>2a\int_0^a f(x)\,dx.
\]

## 关联方法页

- [[MATHWIKI-GS-METHOD-072_积分不等式证明入口链]]

## 具体错点

本题不是不知道 \(f''>0\) 代表凸性，而是入口选择过绕。原思路先从凸函数弦线、Taylor 或点态不等式入手，能得到一些局部比较，但很难直接落到

\[
3\int_0^a x f(x)\,dx
\quad\text{与}\quad
2a\int_0^a f(x)\,dx
\]

这种带权积分整体比较上。

更快的第一动作是直接围绕选项移项，把 B 写成

\[
\int_0^a x f(x)\,dx-\frac23a\int_0^a f(x)\,dx>0.
\]

然后把固定端点 \(a\) 改成变量 \(t\)，构造同型辅助函数 \(F(t)\)。这样题目就变成证明 \(F(a)>0\)，后续只需要用 \(F''>0\to F'>0\to F>0\) 收口。

## 正确入口

选项本质是在比较两个积分线性组合。第一步不要先散着做弦线或 Taylor 点态比较，而是把 B 移到一边：

\[
\int_0^a x f(x)\,dx-\frac23a\int_0^a f(x)\,dx>0.
\]

接着把固定端点 \(a\) 变成变量 \(t\)，构造辅助函数：

\[
F(t)=\int_0^t x f(x)\,dx-\frac23t\int_0^t f(x)\,dx.
\]

显然

\[
F(0)=0.
\]

对 \(t\) 求导：

\[
\begin{aligned}
F'(t)
&=t f(t)-\frac23\int_0^t f(x)\,dx-\frac23t f(t)\\
&=\frac13t f(t)-\frac23\int_0^t f(x)\,dx.
\end{aligned}
\]

并且

\[
F'(0)=0.
\]

再求导：

\[
F''(t)=\frac13t f'(t)+\frac13f(t)-\frac23f(t)
=\frac13t f'(t)-\frac13f(t).
\]

因为 \(f(0)=0\)，对 \([0,t]\) 使用拉格朗日中值定理：

\[
f(t)-f(0)=t f'(\xi),\qquad 0<\xi<t.
\]

所以

\[
f(t)=t f'(\xi).
\]

又因为 \(f''(x)>0\)，所以 \(f'(x)\) 单调递增，进而

\[
f'(t)>f'(\xi).
\]

于是

\[
F''(t)=\frac13t[f'(t)-f'(\xi)]>0.
\]

因此 \(F'(t)>F'(0)=0\)，再由 \(F(0)=0\) 得

\[
F(t)>0\qquad (t>0).
\]

取 \(t=a\)，得到

\[
\int_0^a x f(x)\,dx-\frac23a\int_0^a f(x)\,dx>0,
\]

即

\[
3\int_0^a x f(x)\,dx>2a\int_0^a f(x)\,dx.
\]

## 方法断点

- `method_trigger`：\(f(0)=0,\ f''>0\)，选项是两个定积分线性组合比较。
- `expected_method`：目标移项，固定上限变量化，构造变上限差值辅助函数，再用二阶导正性和拉格朗日中值定理判号。
- `expected_first_action`：先写 \(\int_0^a x f(x)\,dx-\frac23a\int_0^a f(x)\,dx>0\)，再把 \(a\) 改成 \(t\)。
- `missed_action`：没有先构造同型差值辅助函数；点态不等式路线过绕，难以直接收口到选项。
- `action_gap_type`：B3-METHOD。
- `related_method_card_id`：H11-007。

## 必要提示

看到“定积分线性组合比较”时，优先把候选选项移项成一个差值。若差值里有固定上限 \(a\)，就把 \(a\) 变量化为 \(t\)，让目标变成 \(F(a)>0\)。这类题常常不是直接硬比被积函数，而是通过

\[
F''>0\Rightarrow F'>0\Rightarrow F>0
\]

来完成整体积分比较。

## 复做提醒

看到两个积分线性组合比较，先把候选正确项移到一边，构造

\[
F(t)=\int_0^t x f(x)\,dx-\frac23t\int_0^t f(x)\,dx.
\]

再求 \(F'\)、\(F''\)，用 \(f(0)=0\) 和 \(f''>0\) 通过拉格朗日中值定理判 \(F''>0\)，不要在零散点态不等式里绕太久。
