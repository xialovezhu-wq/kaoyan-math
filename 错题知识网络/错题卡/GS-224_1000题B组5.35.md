# GS-224｜1000题B组5.35

## 题目摘要
已知 $f(0)=0$，且 $f'$ 在 $(0,+\infty)$ 上单调递增，证明 $\frac{f(x)}x$ 在 $(0,+\infty)$ 上单调递增。

## 标准答案
$$\frac{f(x)}x\text{ 在 }(0,+\infty)\text{ 上单调递增。}$$
对任意 $x>0$，由拉格朗日中值定理存在 $\xi_x\in(0,x)$，使 $f(x)=f'(\xi_x)x$；再利用 $f'$ 单调递增比较 $f'(x)$ 与 $f'(\xi_x)$，得到
$$\left(\frac{f(x)}x\right)'=\frac{xf'(x)-f(x)}{x^2}\ge0.$$

## 具体错点
暂无可核验的个人具体错因。题图与生成解析只能确认一个复做风险：题设未给 $f'(0)$，不能在 0 点擅写含端点导数的 Taylor 展开；稳妥入口是拉格朗日中值定理。

## 方法入口
第一动作：先在 $[0,x]$ 上用拉格朗日中值定理，把 $f(x)$ 转成 $f'(\xi_x)x$；“曾误用 0 点 Taylor”仍待用户作答证据确认。

## 复做提醒
端点 0 未给导数时，不写含 $f'(0)$ 的 Taylor；先用拉格朗日中值定理写 $f(x)=f'(\xi_x)x$。

## 易错陷阱
不能擅用f'(0)；端点导数未给出；单调导数比较
