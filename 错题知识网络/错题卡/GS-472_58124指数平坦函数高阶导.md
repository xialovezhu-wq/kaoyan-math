# GS-472 58124 指数平坦函数高阶导

## 题目摘要

设
\[
f(x)=
\begin{cases}
e^{-1/x^2}, & x\ne0,\\
0, & x=0.
\end{cases}
\]
求 \(f^{(n)}(0)\)。

## 标准答案

对任意正整数 \(n\)，\(f^{(n)}(0)=0\)。

## 具体错点

忽略了分段函数在分段点处不能直接沿用非分段点表达式求导；求 \(f^{(n)}(0)\) 时，应先从导数定义出发，再利用 \(e^{-1/x^2}\) 比任意幂函数趋零更快，归纳得到每阶导数在 0 处都为 0。

## 标签

- 知识点：一元函数微分学应用, 导数定义, 高阶导数, 分段函数连续可导, 指数函数压过幂函数
- 错因：题型识别失败, 方法选择错误, 条件忽略, 过程跳步
- 方法：先判型, 导数定义, 换元, 归纳法, 逐阶比较, 标准化计算流程
- 陷阱：分段点, 适用条件, 量纲/阶数, 非分段表达式误用, 极限过程
- 关键词：日期已归档, 分段点, 高阶导数, 指数平坦函数, 指数压过幂函数

## 必要提示

分段点处求导先用定义，不要把 \(x\ne0\) 的导数公式直接代入 0。
核心极限是：对任意正整数 \(m\)，
\[
\lim_{x\to0}\frac{e^{-1/x^2}}{x^m}=0.
\]

## 错题复发记录

- 第 1 次：2026-05-19，分段点处高阶导数没有先回到定义，误把非分段点求导公式当成 0 点可直接使用的表达式。

## 复做提醒

看到“分段函数 + \(f^{(n)}(0)\)”先停一下：0 点一律用导数定义；非零点求导公式只能帮助归纳 \(x\ne0\) 的结构，不能直接替代 0 点判断。
