# GS-506 57844 交叉乘反推商函数

## 题目摘要

设 \(f(x)\) 在 \([0,+\infty)\) 上二阶可导，\(f(0)=0\)，且 \(f''(x)<0\)。当 \(0<a<x<b\) 时，判断关于 \(a f(x), x f(a), b f(x), x f(b)\) 的大小关系；正确选项为 \(b f(x)>x f(b)\)。

## 标准答案

B。

## 具体错点

选项反复出现 \(a f(x)\) 与 \(x f(a)\)、\(b f(x)\) 与 \(x f(b)\) 的交叉相乘结构时，没有先同除正数转成 \(\frac{f(a)}a,\frac{f(x)}x,\frac{f(b)}b\) 的比较，因而没有反推出辅助函数 \(F(t)=\frac{f(t)}t\)；误构造 \(x f(x)\) 后得到 \(f(x)+xf'(x)\)，这个符号无法由题设 \(f''(x)<0\) 判断。

## 必要提示

选项里有 \(a f(x)\) 与 \(x f(a)\)、\(b f(x)\) 与 \(x f(b)\) 时，先同除正数，转为比较 \(\frac{f(t)}t\)。
令 \(F(t)=\frac{f(t)}t\)，由拉格朗日中值定理 \(f(t)=t f'(\xi)\)，且 \(f''<0\Rightarrow f'\) 单调递减，可得 \(F'(t)<0\)。
因此 \(0<a<x<b\) 时 \(\frac{f(a)}a>\frac{f(x)}x>\frac{f(b)}b\)，推出 \(b f(x)>x f(b)\)。

## 方法断点

- 题面触发：选项反复出现 \(a f(x)\)、\(x f(a)\)、\(b f(x)\)、\(x f(b)\) 的交叉相乘结构，且 \(0<a<x<b\)
- 应调方法：先同除正数，把交叉乘不等式转成商函数 \(\frac{f(t)}t\) 的单调比较。
- 第一动作：先把选项同除对应正数，转成比较 \(\frac{f(a)}a,\frac{f(x)}x,\frac{f(b)}b\)，再令 \(F(t)=\frac{f(t)}t\) 用 \(f''<0, f(0)=0\) 判单调。
- 漏掉动作：看到交叉乘结构时没有先同除正数转成 \(f(t)/t\) 的比较，误去构造 \(x f(x)\) 或套乘积求导。
- 断点类型：方法调取失败 / B3-METHOD
- 下次提醒：看到 \(a f(x)\) 与 \(x f(a)\) 这类交叉乘，先同除成 \(f(t)/t\)，再用凹凸性或导数判断这个商函数的单调性。
