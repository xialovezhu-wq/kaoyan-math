# GS-627 77447 两直线平行平面

## 题目摘要

求过原点且与两条空间直线都平行的平面方程：
\[
\begin{cases}
x=1,\\
y=-1+t,\\
z=2+t
\end{cases}
\qquad
\frac{x+1}{1}=\frac{y+2}{2}=\frac{z-1}{1}.
\]

## 标准答案

\[
x-y+z=0.
\]

## 具体错点

本轮复做暴露的是一条从概念到计算的综合断点。用户能正确提取两个方向向量，但起初不知道平面一般式，也没有区分“过原点只令常数项为 0”和“已经得到完整平面方程”；随后误以为两条直线都平行于同一平面就一定彼此平行。

在向量关系上，用户此前不理解法向量为什么分别与两个平面内方向垂直，也不熟悉“垂直等价于点乘为 0”、点乘计算和叉乘求共同垂直向量。经讲解后已经能使用叉乘的行列式写法，但按第一行展开时漏掉 $\boldsymbol j$ 项的代数余子式符号 $(-1)^{1+2}=-1$，因此把正确平面误写为 $x+y+z=0$。

两条直线的方向向量分别为：
\[
s_1=(0,1,1),\qquad s_2=(1,2,1).
\]
因为两条直线都平行于所求平面，所以 \(s_1,s_2\) 都是平面内方向。平面法向量同时垂直于这两个方向：
\[
n=s_1\times s_2=(-1,1,-1).
\]
过原点的点法式：
\[
-x+y-z=0,
\]
等价为
\[
x-y+z=0.
\]

## 方法断点

- `method_trigger`：与两直线都平行，且过原点，求平面方程。
- `expected_method`：先写平面一般式并用过原点确定常数项，再把两条直线的方向向量视为平面内方向，用点乘为 0 或叉乘求法向量；展开叉乘行列式时检查“正、负、正”。
- `expected_first_action`：先写 $Ax+By+Cz+D=0$，由过原点得到 $D=0$，并明确当前还缺法向量 $\boldsymbol n=(A,B,C)$。
- `missed_action`：平面模板、法向量与方向向量的垂直关系、点乘和叉乘计算均不熟；后续又漏掉 $\boldsymbol j$ 项的代数余子式负号。
- `action_gap_type`：B4-CHAIN。
- `related_method_card_id`：本地 registry 正式 ID 采用 `H00-007`；`B17-001`、`B17-002` 是第 17 讲知识树节点，记录在 `lecture_refs` 中。

## 标签

- 知识点：向量代数与空间解析几何, 空间直线与平面, 空间平面方程, 方向向量, 法向量, 叉乘, 行列式, 代数余子式
- 错因：平面一般式不熟, 法向量与平面内方向关系不清, 同一平面平行误推两直线平行, 点乘判垂直不熟, 叉乘定义与计算不熟, 代数余子式符号遗漏, 运算路径不稳
- 方法：平面一般式, 平面点法式, 方向向量提取, 点乘判垂直, 叉乘求法向量, 叉乘行列式展开, 代数余子式符号检查
- 陷阱：过原点只令常数项为 0, 同平面平行不推出两直线平行, 叉乘不是矩阵乘法, 第一行展开符号为正负正

## 必要提示

空间平面先写“点 + 法向量”。两条直线都平行于平面时，两个方向向量都是平面内方向，所求法向量分别与它们点乘为 0；用叉乘行列式求法向量时，按第一行展开必须检查“正、负、正”。

- 第 2 次：2026-07-17，已能提取两个方向向量，但平面一般式、同平面平行关系、法向量垂直关系、点乘与叉乘计算均不熟；讲解后又漏掉叉乘行列式中 $\boldsymbol j$ 项的代数余子式负号，误得 $x+y+z=0$。
- 第 3 次：2026-07-26，叉乘计算正确，但向量角色仍命名混乱；得到平面法向量后误用直线对称式，并漏用题设原点。提示切换到平面点法式后自行完成。

## 复做提醒

看到求平面方程，先写“点 + 法向量”；若题目给两条平行于平面的直线，就让法向量分别与两个方向向量点乘为 0，再用叉乘求法向量。叉乘行列式按第一行展开后，检查“正、负、正”，最后回验两个点乘是否都为 0。
