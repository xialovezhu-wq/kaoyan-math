# GS-572 57845 原函数奇偶周期单调判断

## 题目摘要

设 \(f(x)\) 是连续函数，\(F(x)\) 是 \(f(x)\) 的原函数，则（　）。

- (A) 当 \(f\) 为奇函数时，\(F\) 必为偶函数；
- (B) 当 \(f\) 为偶函数时，\(F\) 必为奇函数；
- (C) 当 \(f\) 为周期函数时，\(F\) 必为周期函数；
- (D) 当 \(f\) 为单调函数时，\(F\) 必为单调函数。

## 标准答案

A。

令 \(G(x)=\int_0^x f(t)dt\)，则 \(G'=f\)，任意原函数 \(F=G+C\)。

- A 对：f 奇 ⇒ G 偶 ⇒ F=G+C 仍偶（常数函数本身是偶函数）。
- B 错：f 偶 ⇒ G 奇，但 F=G+C 仅当 C=0 才奇；反例 f=1（偶），F=x+1。
- C 错：周期原函数需 \(\int_0^T f=0\)；反例 f=1（任意 T 为周期），F=x 不周期。
- D 错：F 单调看 \(F'=f\) 的正负，不是看 f 是否单调；反例 f=x（单增），F=x²/2 先减后增。

## 具体错点

只记住“偶函数积分变奇函数”这条片面规律，没有先写 \(F'=f\)、构造 \(G=\int_0^x f\) 再补 \(F=G+C\)。漏掉常数 C，把“特殊原函数 G 的奇偶性”直接当成“任意原函数 F 的奇偶性”，并把周期、单调也当成积分后必然保留。

## 方法断点

- `method_trigger`：题面“F 是 f 的原函数”+选项含奇/偶/周期/单调。
- `expected_method`：写 F'=f → 构造 G=∫₀ˣf → F=G+C → 逐一判 C 的影响并举反例。
- `expected_first_action`：先写 F'(x)=f(x)，令 G(x)=∫₀ˣf(t)dt，再写 F=G+C。
- `missed_action`：没把任意原函数写成 F=G+C，漏常数 C，套用片面的“积分改变奇偶性”。
- `action_gap_type`：A-CONCEPT（对“任意原函数=特殊原函数+常数 C”理解不牢）。
- `related_method_card_id`：H09-008（变限积分求导），联动 H04-006（奇偶周期高阶导）、H08-008（积分对称周期）、H05-002（单调性）。

## 必要提示

原函数题第一动作：写 \(F'=f\)，令 \(G=\int_0^x f\)，再写 \(F=G+C\)，C 不能默认为 0。

判性质口诀：奇函数加 C 不一定奇（须 C=0），偶函数加 C 仍偶；周期原函数须整周期积分为 0；F 的单调看 \(F'=f\) 的符号。

## 错题复发记录

## 复做提醒

看到“原函数”先写 F'=f、再写 F=∫₀ˣf+C；任何关于 F 奇偶/周期/单调的结论，都要先问“常数 C 在不在、它会不会破坏这个性质”。
