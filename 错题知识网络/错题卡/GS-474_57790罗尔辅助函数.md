# GS-474 57790 罗尔辅助函数

## 题目摘要

设 \(f(x)\) 在 \([a,b]\) 上连续、在 \((a,b)\) 内可导，\(0<a<b\)，且 \(f(a)=f(b)=0\)。证明存在 \(\xi,\eta\in(a,b)\)，使
\[
2f(\xi)+\xi f'(\xi)=0,\qquad 2\eta f(\eta)-f'(\eta)=0.
\]

## 标准答案

构造 \(F(x)=x^2f(x)\)、\(G(x)=e^{-x^2}f(x)\)，分别用罗尔定理。

## 具体错点

看到端点值相等且目标式含 \(f,f'\) 时，必须先反向构造使 \(F'(\xi)=0\)；第一问构造 \(F=x^2f\) 后还要用 \(\xi>0\) 才能除以 \(\xi\)，第二问要先把 \(2xf-f'=0\) 改写为 \(f'-2xf=0\)，再构造 \(G=e^{-x^2}f\)，不能使用分母含 \(f(x)\) 且端点为零的商式辅助函数。

## 必要提示

罗尔题的目标式若含 \(f,f'\)，先反推“它是不是某个乘积函数的导数”。
第一问用 \((x^2f)'=x(2f+xf')\)，因 \(\xi>0\) 可除以 \(\xi\)；第二问用 \((e^{-x^2}f)'=e^{-x^2}(f'-2xf)\)。

## 方法断点

- 题面触发：题目给出 \(f(a)=f(b)=0\)，并要求证明存在点使含 \(f(x)\) 与 \(f'(x)\) 的表达式等于 0。
- 应调方法：先用罗尔定理总入口判断需要构造辅助函数；第一问构造 \(F(x)=x^2f(x)\)；第二问先把 \(2xf(x)-f'(x)=0\) 改写成 \(f'(x)-2xf(x)=0\)，再构造 \(G(x)=e^{-x^2}f(x)\)。
- 第一动作：先把目标式看成某个辅助函数导数为 0 的结果；第二问先改写为 \(f'(x)-2xf(x)=0\)。
- 漏掉动作：第二问没有及时想到指数乘子 \(e^{-x^2}\)，并误尝试了含 \(\frac1{f(x)}\) 的分式辅助函数；第一问收尾时漏查 \(\xi>0\) 后再除以 \(\xi\)。
- 断点类型：动作链断裂 / B4-CHAIN
- 下次提醒：目标式含 \(f\) 和 \(f'\) 时，先问它是不是 \((m(x)f(x))'\)；若目标是 \(f'(x)+p(x)f(x)\)，找 \(m(x)\) 使 \(\frac{m'}m=p(x)\)，再检查辅助函数是否闭区间连续、开区间可导、端点相等。

## 错题复发记录

- 第 1 次：2026-05-19，没有把目标等式反向看成辅助函数导数为零。
- 第 2 次：2026-05-22，复做评分 2 分；第一问已能构造 \(x^2f(x)\)，第二问仍未构造出指数因子辅助函数 \(e^{-x^2}f(x)\)。
- 第 3 次：2026-06-12，第一问漏用 \(\xi>0\) 完成除法收尾；第二问误尝试 \(x^2/f(x)\) 且没有检查 \(f(a)=f(b)=0\) 带来的定义域风险，指数因子符号也没有及时从 \(e^{x^2}\) 改为 \(e^{-x^2}\)。

## 复做提醒

看到“端点值相等 + 存在点使含 \(f,f'\) 的式子为 0”时，不要乱构造分式；先把目标式反推成某个乘积函数的导数，再用罗尔定理。第二问这类 \(f'-2xf\) 结构要立刻想到 \((e^{-x^2}f)'=e^{-x^2}(f'-2xf)\)。
