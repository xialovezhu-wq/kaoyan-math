# GS-623 57931-3 分母整体线性拆分

## 题目摘要

求不定积分
\[
\int \frac{\sin x}{\sin x+\cos x}\,dx.
\]

## 标准答案

\[
\frac12x-\frac12\ln|\sin x+\cos x|+C.
\]

## 具体错点

本题不要先硬拆三角函数。分母
\[
F(x)=\sin x+\cos x
\]
是一个明显整体，第一步应算
\[
F'(x)=\cos x-\sin x.
\]
再检查分子能否由 \(F\) 和 \(F'\) 线性组合出来：
\[
\sin x=A(\cos x-\sin x)+B(\sin x+\cos x).
\]
比较 \(\sin x,\cos x\) 系数：
\[
-A+B=1,\qquad A+B=0,
\]
得
\[
A=-\frac12,\qquad B=\frac12.
\]
因此
\[
\sin x=-\frac12(\sin x+\cos x)'+\frac12(\sin x+\cos x),
\]
原积分化为
\[
-\frac12\int\frac{d(\sin x+\cos x)}{\sin x+\cos x}+\frac12\int dx.
\]

## 方法断点

- `method_trigger`：分母是 \(\sin x+\cos x\) 的整体，分子是 \(\sin x\)。
- `expected_method`：设 \(F=\sin x+\cos x\)，用 \(F'\) 和 \(F\) 线性组合分子。
- `expected_first_action`：先算 \(F'(x)=\cos x-\sin x\)，再设 \(\sin x=A(\cos x-\sin x)+B(\sin x+\cos x)\)。
- `missed_action`：没有把分母看成整体，也没有用分母导数参与拆分分子。
- `action_gap_type`：B3-METHOD（原指令“分母整体法触发断点”已按本地 schema 归一）。

## 必要提示

分式积分中，分母若是明显整体 \(F(x)\)，第一问不是“怎么拆三角函数”，而是“分母导数是什么？分子能不能由 \(F\) 和 \(F'\) 线性组合出来？”

## 错题复发记录

## 定义域与原函数区间

必须先排除分母为零的点：
\[
\sin x+\cos x=0
\quad\Longleftrightarrow\quad
x=\frac{3\pi}{4}+k\pi,\qquad k\in\mathbb Z.
\]
标准答案在上述点分隔出的每个连通区间内成立，积分常数可分区间不同。

## 复做提醒

看到 \(\frac{\text{分子}}{\sin x+\cos x}\) 这类题，先把分母设成 \(F(x)\)，算 \(F'(x)\)，再检查分子能否写成 \(AF'(x)+BF(x)\)。
