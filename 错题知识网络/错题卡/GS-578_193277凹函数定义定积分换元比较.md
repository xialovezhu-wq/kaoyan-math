# GS-578 193277 凹函数定义定积分换元比较

## 题目摘要

设 f(x) 在 [0,1] 上是凹函数、非负连续，且 f(0)=0，比较 \(\int_0^{1/2}f\) 与 \(\int_0^1 f\) 的关系（选 A：4∫₀^{1/2}f≤∫₀¹f）。

## 题面术语边界

题图原文是“凹函数”，本卡保留这一字面题面，不改写为“凸函数”。本题采用的定义方向是

\[
f\bigl(\lambda x+(1-\lambda)y\bigr)
\le \lambda f(x)+(1-\lambda)f(y),\qquad 0\le\lambda\le1.
\]

不同教材对“凹/凸”的中文命名可能不同；本卡一律以题图原文和上述不等式方向消歧。

## 标准答案

A。凹函数定义：\(\frac t2=\frac12 t+\frac12\cdot0\) ⇒ \(f(\frac t2)\le\frac12 f(t)+\frac12 f(0)=\frac12 f(t)\)（用 f(0)=0）。两边在 [0,1] 积分得 \(\int_0^1 f(\frac t2)dt\le\frac12\int_0^1 f\)；对左边换元 x=t/2 得 \(\int_0^1 f(\frac t2)dt=2\int_0^{1/2}f\)。故 \(2\int_0^{1/2}f\le\frac12\int_0^1 f\)，即 \(4\int_0^{1/2}f\le\int_0^1 f\)，选 A。

## 具体错点

看到凹函数没回定义，默认 f 可二阶导而走泰勒；并在端点 x=0 误用费马引理推 f'(0)=0（费马要内部极值点且可导，反例 f=x：f(0)=0、f≥0 但 f'₊(0)=1）。题目只给凹 + 非负连续，最稳的是用凹函数定义把自变量写成线性组合，配 f(0)=0 消项，再换元 + 保序。

## 方法断点

- `method_trigger`：凹函数（仅连续/非负）+ f(0)=0 + 比较半区间与整区间定积分。
- `expected_method`：凹函数定义写线性组合（t/2=½t+½·0）→ 配 f(0)=0 → 定积分换元 + 保序。
- `expected_first_action`：先把 t/2 写成 ½t+½·0，用定义得 f(t/2)≤½f(t)+½f(0)。
- `missed_action`：没回定义，默认 f″存在走泰勒、端点 x=0 误用费马引理。
- `action_gap_type`：A-CONCEPT（误以为凹函数必可二阶导、端点能用费马引理）。
- `related_method_card_id`：H11-007（积分不等式；先化点态不等式的最近注册入口），H05-004 与 H18-016 仅作次级提示。

## 必要提示

凹函数题优先回定义：把自变量写成两点线性组合 \(f(\lambda x_1+(1-\lambda)x_2)\le\lambda f(x_1)+(1-\lambda)f(x_2)\)；不默认可导、不写 f″>0、不在端点用费马引理。

本题取 x₁=t、x₂=0、λ=½，配 f(0)=0 得 f(t/2)≤½f(t)，再换元 x=t/2 + 积分保序。
