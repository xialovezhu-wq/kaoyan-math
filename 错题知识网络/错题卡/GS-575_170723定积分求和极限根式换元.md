# GS-575 170723 定积分求和极限根式换元

## 题目摘要

求 \(\displaystyle\lim_{n\to\infty}\sum_{k=1}^{n}\int_k^{k+1}\frac{dx}{x\sqrt{x-1}}\)。选项 (A) 1；(B) π/2；(C) π；(D) 2π。

## 标准答案

C，π。

1. 区间可加性：\(\sum_{k=1}^n\int_k^{k+1}=\int_1^{n+1}\)，取极限得 \(\int_1^{+\infty}\frac{dx}{x\sqrt{x-1}}\)。
2. 根式换元 \(t=\sqrt{x-1}\)：\(x=t^2+1,\ dx=2t\,dt\)，\(\frac{dx}{x\sqrt{x-1}}=\frac{2t\,dt}{(t^2+1)t}=\frac{2}{1+t^2}\,dt\)。
3. \(\int_0^{+\infty}\frac{2}{1+t^2}\,dt=2\arctan t\Big|_0^{+\infty}=2\cdot\frac\pi2=\pi\)。

（等价望远镜：原函数 \(2\arctan\sqrt{x-1}\)，\(\int_k^{k+1}=2\arctan\sqrt k-2\arctan\sqrt{k-1}\) 相消得 \(2\arctan\sqrt n\to\pi\)。）

## 具体错点

望远镜方向对，但为凑相消强行错误拆分 \(\frac1{x\sqrt{x-1}}\)：拆成 \(\frac1{\sqrt{x-1}}-\frac1x\)（通分分子是 \(x-\sqrt{x-1}\neq1\)）或 \(\frac a x+\frac b{\sqrt{x-1}}\)（要 \(a\sqrt{x-1}+bx\equiv1\)，异类函数不可能）。没触发根式换元 \(t=\sqrt{x-1}\)，得到错误的 \(2\sqrt n-\ln n\) 发散假结果。

## 方法断点

- `method_trigger`：∑∫ₖ^{k+1} 同被积函数（区间首尾相接）+ 被积式含 √(x-1) 与 x。
- `expected_method`：区间可加性合并成 ∫₁^{n+1}（→反常积分）→ 令 t=√(x-1) → 反正切积分。
- `expected_first_action`：写成 ∫₁^{n+1} 1/(x√(x-1))dx，再令 t=√(x-1)。
- `missed_action`：没合并、没换元，反而强行拆成不成立的 1/√(x-1)-1/x 或 a/x+b/√(x-1)。
- `action_gap_type`：B3-METHOD（方法调取失败：调成强行拆分而非根式换元）。
- `related_method_card_id`：H09-003（第二类换元/根式换元），联动 H11-001（定积分可加性入口）、H08-005（反常积分）、H16-008（望远镜 f(n)-f(n-1)）。

## 必要提示

看到 √(x-1) 与 x 同现，令 t=√(x-1)（x=t²+1），把 x 与根号统一，被积式化为 2/(1+t²)。

任何“裂项/拆分”前先通分还原：右边通分能否变回原式？不能就不要拆。异类函数（如 √(x-1) 与 x）不存在常数系数拆分。

## 错题复发记录

- 第 1 次：2026-06-08，望远镜方向对但强行错误拆分被积函数，没触发根式换元 t=√(x-1)。

## 复做提醒

∑∫ₖ^{k+1} 同被积函数：先用区间可加性合并成单个（反常）积分；遇 √(x-1) 与 x 同现优先根式换元 t=√(x-1)，并同步改上下限；望远镜的相消来自正确原函数，不是来自硬拆。
