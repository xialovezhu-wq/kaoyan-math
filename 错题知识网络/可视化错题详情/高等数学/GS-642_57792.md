## 复述

- 题目定位：变上限积分函数在闭区间上的最大值与最小值
- 正确第一步：求出 $f'(x)$ 后，先用配方或判别式确认分母符号，再令分子为 0 找内部驻点。
- 核心方法：变上限积分求导；导数判单调；驻点求解；二次式配方判号；函数值比较；标准化计算流程
- 易错触发：求出变上限积分函数的导数后，没有先令 $f'(x)=0$ 找内部驻点并建立闭区间候选点表；同时把分母 $x^2-x+1$ 误读成 $(x-1)^2-x$，没有用配方或判别式确认分母恒正，导致导数符号判断不稳；最后漏掉端点值与驻点值的统一比较，并在代入 $x=\frac12$ 时把 $\frac14-\frac12+1$ 误算成 $\frac12$。

###### ① 性质线

| 工具 | 理由说明 |
|---|---|
| 与字母无关性 | $\int_a^b f(x)\,dx$ 中变量符号随便换，不影响值 |
| 线性性 | $\int (af+bg)=a\int f + b\int g$ |
| 方向性 | $\int_a^b = -\int_b^a$ |
| 奇偶性 | 奇函数对称区间为 $0$，偶函数加倍 |
| 可加（可拆）性 | $[a,b]=[a,c]+[c,b]$ |
| “祖孙三代” | $\int_a^x f(t)dt,\ f(x),\ f'(x)$ 会互相出现的套路 |
| “祖孙三代”+周期性 | 有周期时区间拆周期最省力 |

核心标签：$D_1$（常规操作）＋化归

---

###### ② 公式线

| 工具 | 理由说明 |
|---|---|
| 牛顿–莱布尼茨公式 | $\int_a^b f' = f(b)-f(a)$ |
| 上、下限含参公式 | 变上限积分求导/换序套路 |
| 中值定理（积分型） | 存在 $\xi$，$\int_a^b f = f(\xi)(b-a)$ |
| 换元积分法 | 换变量把式子变干净 |
| 分部积分 | $\int u\,dv = uv- \int v\,du$ |
| 区间中点积分公式 | 对称+拆区间的神器 |

核心标签：$D_1$+$D_{23}$(化归经典)+$D_4$(数形结合)
