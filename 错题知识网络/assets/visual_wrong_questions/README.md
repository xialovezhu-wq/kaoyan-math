# visual_wrong_questions 图片资产目录

本目录保存从 MarginNote 4 导出包抽取的题目图片和解析图片副本。

推荐结构：

```text
错题知识网络/assets/visual_wrong_questions/
  GS-633/
    question_01.png
    solution_01.png
    solution_02.png
  LA-001/
    question_01.png
    solution_01.png
```

命名规则：

- 题目图片：`question_01.png`、`question_02.png`
- 解析图片：`solution_01.png`、`solution_02.png`
- 多图按 Obsidian 详情页中的显示顺序编号。

边界：

- 图片资产只供 `可视化错题详情/` 页面展示。
- 不把图片复制进 `错题卡/*.md`。
- 不把本目录当作 wrongnet 源数据。
- 如果题号无法确认，先放入 `UNMATCHED/` 并在索引里标记 `needs_id_confirmation`。
