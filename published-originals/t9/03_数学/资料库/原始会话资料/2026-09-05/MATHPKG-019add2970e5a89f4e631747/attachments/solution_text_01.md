# 28-12 · ID 57761｜向量模长差的极限


### 题面转录
设 $\alpha$ 与 $\beta$ 是非零常向量，$|\beta|=2$，$|\beta|$ 表示 $\beta$ 的模，$\alpha$ 与 $\beta$ 之间的夹角为 $\pi/3$，求
\[
\lim_{x\to0}\frac{|\alpha+x\beta|-|\alpha|}{x}.
\]
**本轮解析与对话采用的答案：** $1$。题面没有给出 $|\alpha|$ 的具体数值。

### 涉及知识点
向量的模与标量、点积与叉积的区别；$\beta\cdot\beta=|\beta|^2$ 与 $\beta\times\beta=\mathbf0$；平方差有理化；$|u|^2=u\cdot u$；极限的四则运算和连续性；高阶无穷小；导数定义与复合函数求导。

### 本轮学习过程索引
用户先尝试叉乘替换，并把 $\sin(\pi/3)$ 记成 $1/2$；随后追问“自身点积是否为零”“为什么约去 $x$ 后可以取极限”“$4x$ 消失是否损失精度”。讲解逐步区分点积/叉积、向量/模长、函数值/极限，并转向有理化。最后用户正确完成变式 $\lim_{x\to0}(3+4x)/(2+x)=3/2$。来源：T01、T03、T05、T07。

**证据支持的学习状态：** 已在完整讲解后理解直接取极限的这个局部机制，并完成上述变式；没有展示脱离讲解后独立重做整道原题。原回复 T08 的“在局部提示和纠正后完成理解”原样保留，不将它自动升级为独立掌握。

### 便于定位的最终方法
\[
\frac{|\alpha+x\beta|-|\alpha|}{x}
=\frac{2\alpha\cdot\beta+x\beta\cdot\beta}{|\alpha+x\beta|+|\alpha|}\quad(x\ne0).
\]
分母趋于 $2|\alpha|\ne0$，故极限为 $\alpha\cdot\beta/|\alpha|=|\beta|\cos(\pi/3)=1$。该式是对 T02、T04、T06 的归纳，不替代原对话。

### T02 · 助手

你卡住的地方很典型。这道题真正的关键不是叉乘，而是**把“向量的模”转成“点积”**。

先纠正你前面一个小计算：

\[
\angle(\alpha,\beta)=\frac{\pi}{3}
\]

所以

\[
\sin\frac{\pi}{3}=\frac{\sqrt3}{2},
\qquad
\cos\frac{\pi}{3}=\frac12.
\]

因此

\[
|\alpha\times\beta|
=|\alpha||\beta|\sin\frac{\pi}{3}
=|\alpha|\cdot2\cdot\frac{\sqrt3}{2}
=\sqrt3|\alpha|,
\]

**并不是 \(|\alpha|\)**。

所以你不能把原题里的 \(|\alpha|\) 换成 \(|\alpha\times\beta|\)。

# 一、这道题最推荐的思路：分子有理化

原式：

\[
L=\lim_{x\to0}
\frac{|\alpha+x\beta|-|\alpha|}{x}.
\]

你说：

> \(\alpha\) 和 \(\beta\) 提不出去。

对，因为

\[
|\alpha+x\beta|
\]

本来就**不能像普通代数式那样提取 \(\alpha\)**。

原因是 \(\alpha,\beta\) 不是同方向的向量。只有类似

\[
|\alpha+x\alpha|
=|(1+x)\alpha|
=|1+x||\alpha|
\]

才能提。

所以看到

\[
|A|-|B|
\]

这种形式，尤其又是 \(0/0\)，一个非常自然的操作就是：

\[
\boxed{\text{乘 }(|A|+|B|)}
\]

也就是“平方差有理化”。

于是：

\[
L=
\lim_{x\to0}
\frac{|\alpha+x\beta|-|\alpha|}{x}
\cdot
\frac{|\alpha+x\beta|+|\alpha|}
{|\alpha+x\beta|+|\alpha|}.
\]

得到

\[
L=
\lim_{x\to0}
\frac{|\alpha+x\beta|^2-|\alpha|^2}
{x\left(|\alpha+x\beta|+|\alpha|\right)}.
\]

到这里是本题最关键的一步。

---

## 二、为什么平方以后突然就能算了？

因为向量模长平方有公式：

\[
\boxed{|u|^2=u\cdot u}
\]

所以

\[
|\alpha+x\beta|^2
=
(\alpha+x\beta)\cdot(\alpha+x\beta).
\]

展开：

\[
=\alpha\cdot\alpha
+2x\alpha\cdot\beta
+x^2\beta\cdot\beta.
\]

而

\[
|\alpha|^2=\alpha\cdot\alpha.
\]

因此相减以后：

\[
|\alpha+x\beta|^2-|\alpha|^2
=
2x\alpha\cdot\beta+x^2\beta\cdot\beta.
\]

代回去：

\[
L=
\lim_{x\to0}
\frac{2x\alpha\cdot\beta+x^2\beta\cdot\beta}
{x(|\alpha+x\beta|+|\alpha|)}.
\]

约掉 \(x\)：

\[
L=
\lim_{x\to0}
\frac{2\alpha\cdot\beta+x\beta\cdot\beta}
{|\alpha+x\beta|+|\alpha|}.
\]

现在就可以直接令 \(x\to0\)：

\[
L=
\frac{2\alpha\cdot\beta}
{2|\alpha|}
=
\frac{\alpha\cdot\beta}{|\alpha|}.
\]

接下来利用点积：

\[
\alpha\cdot\beta
=
|\alpha||\beta|\cos\frac{\pi}{3}.
\]

因此

\[
L
=
\frac{|\alpha||\beta|\cos\frac{\pi}{3}}
{|\alpha|}
=
|\beta|\cos\frac{\pi}{3}.
\]

已知

\[
|\beta|=2,
\]

所以

\[
L
=
2\times\frac12
=
\boxed{1}.
\]

# 四、为什么 \(|\alpha+x\beta|'\) 不是 \(|\beta|=2\)？

你刚才的想法大概是：

\[
(\alpha+x\beta)'=\beta
\]

于是猜：

\[
|\alpha+x\beta|'=|\beta|.
\]

**这里不能这么做。**

也就是说：

\[
\boxed{
\frac{d}{dx}|u(x)|
\neq
|u'(x)|
}
\]

一般情况下是不成立的。

最简单的反例：

\[
f(x)=|x|.
\]

如果按你的想法：

\[
f'(x)=|1|=1.
\]

但实际上：

\[
(|x|)'=
\begin{cases}
1,&x>0\\
-1,&x<0
\end{cases}
\]

显然不恒等于 \(1\)。

# 五、向量模长到底怎么求导？

设

\[
f(x)=|\alpha+x\beta|.
\]

先不要直接对模求导，而是写成平方根：

\[
|\alpha+x\beta|
=
\sqrt{(\alpha+x\beta)\cdot(\alpha+x\beta)}.
\]

令

\[
g(x)
=
(\alpha+x\beta)\cdot(\alpha+x\beta).
\]

那么

\[
f(x)=\sqrt{g(x)}.
\]

用链式法则：

\[
f'(x)
=
\frac{g'(x)}{2\sqrt{g(x)}}.
\]

而

\[
g(x)
=
\alpha\cdot\alpha
+2x\alpha\cdot\beta
+x^2\beta\cdot\beta.
\]

所以

\[
g'(x)
=
2\alpha\cdot\beta
+2x\beta\cdot\beta.
\]

于是

\[
f'(x)
=
\frac{
2\alpha\cdot\beta+2x\beta\cdot\beta
}{
2|\alpha+x\beta|
}.
\]

约掉 2：

\[
\boxed{
f'(x)
=
\frac{(\alpha+x\beta)\cdot\beta}
{|\alpha+x\beta|}
}
\]

这就是**向量模长函数的求导公式**。

所以 \(x=0\)：

\[
f'(0)
=
\frac{\alpha\cdot\beta}{|\alpha|}.
\]

再用点积：

\[
\alpha\cdot\beta
=
|\alpha||\beta|\cos\frac\pi3,
\]

得到：

\[
f'(0)
=
|\beta|\cos\frac\pi3
=
2\times\frac12
=
\boxed{1}.
\]

---

# 六、所以你用洛必达也完全可以

原式：

\[
\lim_{x\to0}
\frac{|\alpha+x\beta|-|\alpha|}{x}.
\]

是 \(0/0\) 型。

分母：

\[
x'=1.
\]

分子：

\[
\frac{d}{dx}
\left(|\alpha+x\beta|-|\alpha|\right)
=
\frac{(\alpha+x\beta)\cdot\beta}
{|\alpha+x\beta|}.
\]

所以洛必达：

\[
L
=
\lim_{x\to0}
\frac{(\alpha+x\beta)\cdot\beta}
{|\alpha+x\beta|}.
\]

令 \(x=0\)：

\[
L
=
\frac{\alpha\cdot\beta}{|\alpha|}
=
|\beta|\cos\frac\pi3
=
\boxed1.
\]

所以你的洛必达方向**没有问题**。

问题只出在你误以为：

\[
\boxed{
(|\alpha+x\beta|)'=|\beta|
}
\]

实际上应该是：

\[
\boxed{
(|\alpha+x\beta|)'
=
\frac{(\alpha+x\beta)\cdot\beta}
{|\alpha+x\beta|}
}
\]

# 七、这个公式其实有非常直观的几何意义

尤其值得理解。

\[
\frac{(\alpha+x\beta)\cdot\beta}
{|\alpha+x\beta|}
\]

把点积展开：

\[
=
\frac{
|\alpha+x\beta||\beta|\cos\theta
}
{|\alpha+x\beta|}
\]

所以

\[
\boxed{
\frac{d}{dx}|\alpha+x\beta|
=
|\beta|\cos\theta
}
\]

其中 \(\theta\) 是当前向量 \(\alpha+x\beta\) 与 \(\beta\) 的夹角。

在 \(x=0\)：

\[
\theta=\angle(\alpha,\beta)=\frac{\pi}{3}.
\]

因此：

\[
f'(0)
=
|\beta|\cos\frac\pi3
=
1.
\]

这句话的几何意义是：

> \(\beta\) 虽然本身长度是 2，但并不是它所有的“运动速度”都在增加 \(\alpha\) 的长度。

真正能够增加模长的，只是 \(\beta\) 在 \(\alpha\) 方向上的投影。

这个投影长度就是：

\[
|\beta|\cos\frac\pi3
=
2\times\frac12
=
1.
\]

所以你刚才问：

> “导完不是只剩一个 \(\beta\) 吗？那模长不就等于 2？”

这里可以抓住一句话：

\[
\boxed{\text{向量变化速度是 }\beta，
\quad\text{但模长变化速度是 }\beta\text{ 在当前向量方向上的投影。}}
\]

所以答案不是 \(2\)，而是

\[
2\cos60^\circ=1.
\]

# 2. 模长为什么可以“平方差有理化”？

可以，但不是因为“向量模长有一个特殊的有理化定义”。

而是因为：

\[
|\alpha+x\beta|
\]

算出来以后，本身就是一个**普通的非负实数**。

例如设

\[
A=|\alpha+x\beta|,\qquad B=|\alpha|.
\]

那么 \(A,B\) 都是实数。

当然满足普通代数恒等式：

\[

### 题目说“平面 \(\pi\) 过直线 \(L\)”

严格含义就是：

\[
\boxed{L\subset \pi}
\]

也就是：

> **直线 \(L\) 上的每一个点都在平面 \(\pi\) 内。**

因此可以直接说：

\[
\boxed{\text{直线 }L\text{ 在平面 }\pi\text{ 内}}
\]

---

你刚才想象的这种情况：

> 一条直线本来在那里，一个平面横着“切一刀”，两者碰到一个点。

数学上不叫“平面过这条直线”，而叫：

\[
\boxed{\text{直线与平面相交}}
\]

或者更准确地说：

\[
\boxed{\text{直线与平面交于一点}}
\]

比如：

\[
L\cap\pi=\{P\}.
\]

这时只有 \(P\) 这一个点同时属于直线和平面，**整条直线并不属于平面**。

---

### 你可以用这个语言体系记

“过”后面跟什么对象，就表示那个对象**整体包含在里面**：

\[
\text{直线过点 }P
\quad\Longrightarrow\quad
P\in L
\]

\[
\text{平面过点 }P
\quad\Longrightarrow\quad
P\in\pi
\]

而

\[
\boxed{
\text{平面过直线 }L
\quad\Longrightarrow\quad
L\subset\pi
}
\]

最后这一条意味着：

\[
\text{直线上的所有点都属于平面。}
\]

所以不是“平面和它碰一下”。

|\mathbf n_{F_2}\cdot\mathbf n_{\pi_1}|
}{
|\mathbf n_{F_2}|\,|\mathbf n_{\pi_1}|
}.
\]

如果算出来

\[
\cos\theta=\frac{\sqrt2}{2},
\]

那就是

\[
\theta=45^\circ.
\]

于是：

\[
\boxed{F_2=0}
\]

也满足全部条件，就必须作为另一个答案保留下来。

所以考试时你可以机械记成：

\[
\boxed{
F_1+\lambda F_2=0
\Rightarrow
\text{求完 }\lambda\text{ 后，额外拿 }F_2=0\text{ 检查剩余条件}
}
\]

这道题里“剩余条件”恰好就是**与 \(\pi_1\) 夹角为 \(45^\circ\)**。
